# Exercise 10.13 — Collapsing two indistinguishable source classes

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 340.

## Solution

Define $`B=0`$ on $`\{1,2\}`$ and $`B=1`$ on $`\{3,4\}`$, and similarly define $`\widehat B`$ from the reproduction. The distortion is exactly binary Hamming loss between these class labels.

### (a)
Under the uniform source, $`B`$ is fair. Zero distortion requires its exact recovery but nothing within each class, so $`R(0)=H(B)=1`$ bit.

### (b)
Data processing bounds $`I(X;\widehat X)\ge I(B;\widehat B)`$. Conversely any binary test channel for the labels can be realized by reproducing a fixed representative, say 1 or 3. Thus the problem has precisely the fair-binary rate-distortion function:
```math
R(D)=1-h_2(D),\quad0\le D\le1/2;\qquad R(D)=0,\quad D\ge1/2.
```
### (c)
Put $`q=p_3+p_4`$. The same reduction gives
```math
R(D)=\begin{cases}
h_2(q)-h_2(D),&0\le D\le\min(q,1-q),\\
0,&D\ge\min(q,1-q).
\end{cases}
```
For completeness, the binary lower bound is $`H(B\mid\widehat B)\le h_2(D)`$. To attain it on the first branch, use an independent error bit $`E\sim\mathrm{Bern}(D)`$ and the backward relation $`B=\widehat B\oplus E`$, with $`\Pr(\widehat B=1)=(q-D)/(1-2D)`$. This lies in $`[0,1]`$ in the stated range. The exceptional endpoint $`q=D=1/2`$ has zero rate and is attained by a constant reproduction. Reproduce the more likely class for the zero-rate branch.

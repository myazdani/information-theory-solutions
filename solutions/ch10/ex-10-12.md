# Exercise 10.12 — Adding a reconstruction option

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 340.

## Solution

The enlarged reproduction alphabet contains all old test channels: assign probability zero to the added symbol for every source value. Such an embedding preserves both distortion and mutual information. Minimizing over the larger feasible set can therefore only lower or preserve $`R(D)`$.

The decrease can be strict. For a fair binary source with Hamming loss, add a new reconstruction symbol having zero distortion for both source symbols. The old zero-distortion rate is 1 bit; always using the new symbol makes the new zero-distortion rate zero. If the added column duplicates an old column, there is no decrease, since its labels can be merged without increasing distortion or mutual information.

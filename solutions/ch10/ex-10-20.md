# Exercise 10.20 — Ordered distortion criteria and two decoders

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 345.

## Solution

### (a)
If $`d_1(x,\widehat x)\le d_2(x,\widehat x)`$ pointwise, then every test channel meeting the second distortion budget also meets the first. Its feasible set is smaller, hence
```math
R_1(D)\le R_2(D).
```
### (b)
Any common description that meets both requirements must in particular support the second decoder, so its rate is at least $`R_2(D)`$. Conversely, use an optimal code for the second criterion and let both decoders output the same reconstruction. Pointwise ordering ensures that the first distortion is also at most $`D`$. Therefore the minimum asymptotic rate is exactly
```math
R=R_2(D).
```
Two reconstruction functions are allowed, but choosing them equal already attains the optimum.

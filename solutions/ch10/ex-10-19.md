# Exercise 10.19 — One description supporting two reconstructions

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 345.

## Solution

Treat the reproduction pair as one vector-valued reproduction symbol. The rate-distortion function is
```math
R(D_1,D_2)=\min_{p(\widehat x_1,\widehat x_2\mid x)}I(X;\widehat X_1,\widehat X_2)
```
subject to $`\mathbb E d_1(X,\widehat X_1)\le D_1`$ and $`\mathbb E d_2(X,\widehat X_2)\le D_2`$. For finite alphabets this is an ordinary rate-distortion theorem with a vector of cost constraints: random covering yields achievability, and the converse follows from
```math
nR\ge I(X^n;\widehat X_1^n,\widehat X_2^n)
\ge\sum_i I(X_i;\widehat X_{1i},\widehat X_{2i})
\ge nR(D_1,D_2),
```
using joint convexity of the constrained function in the last step.

In general it is neither automatically the maximum nor the sum of the separate rates. It satisfies $`\max(R_1(D_1),R_2(D_2))\le R(D_1,D_2)\le R_1(D_1)+R_2(D_2)`$. The upper bound follows from separate descriptions. For example, if $`X=(U,V)`$ consists of independent fair bits and each zero-distortion criterion asks for one different bit, the common description needs 2 bits although each separate rate is 1. If both criteria coincide, a shared reconstruction instead attains the single required rate.

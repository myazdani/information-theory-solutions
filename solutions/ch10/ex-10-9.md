# Exercise 10.9 — Equality conditions for an efficient distortion code

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 339.

## Solution

Let $`J=f_n(X^n)`$ be the code index and $`\widehat X^n=g_n(J)`$. The inequalities (10.58)–(10.71) all have nonnegative slack. A sequence of codes with $`R-R(D)\to0`$ must make their total slack $`o(n)`$. This is an aggregate normalized statement, not a claim that each coordinate is exactly optimal at finite block length.

- (10.58): $`H(J)\le nR`$. Equality means all $`2^{nR}`$ indices are used uniformly. Near equality means only a sublinear entropy deficit from uniformity.
- (10.59): the removed term is $`H(J\mid X^n)`$. Equality means a deterministic encoder. A deterministic encoder and decoder together give a deterministic reconstruction, as in the exercise's example; encoder determinism alone does not force a stochastic decoder to be deterministic.
- (10.61): data processing loses $`I(X^n;J\mid\widehat X^n)`$. Equality means that the reconstruction retains all source information in the index. Redundant indices pointing to the same reconstruction cannot carry additional source information.
- (10.62)–(10.64): these are identities, using iid source independence and the conditional-entropy chain rule.
- (10.65): the gap is $`\sum_i I(X_i;\widehat X_{-i},X^{i-1}\mid\widehat X_i)`$. Equality says each source coordinate is conditionally independent of the other reconstructions and previous source symbols given its own reconstruction. Equivalently, the backward conditional law factors as $`p(x^n\mid\widehat x^n)=\prod_i p(x_i\mid\widehat x_i)`$ on its support.
- (10.66) and (10.68): these simply rewrite terms.
- (10.67): each coordinate's joint law must attain its scalar rate-distortion bound at its actual distortion $`D_i`$; asymptotically the average excess information above those bounds vanishes.
- (10.69): equality in convexity requires equal $`D_i`$ wherever $`R(D)`$ is strictly convex. More generally all used distortions must lie on a common affine face of $`R`$, so unequal allocations can be optimal on a linear segment.
- (10.70) identifies the actual additive average distortion. For (10.71), distinguish this achieved value $`D_{\rm actual}`$ from a target budget $`D_{\rm target}`$. If $`D`$ is defined as the actual distortion, the step is an identity. If it is the permitted budget, the source's explanation invokes monotonicity with $`D_{\rm actual}\le D_{\rm target}`$; equality requires $`R(D_{\rm actual})=R(D_{\rm target})`$. Thus the budget must be tight where $`R`$ is strictly decreasing, while both distortions may differ on a flat segment.

These constraints explain the near-uniform use of descriptions, absence of wasted encoder randomness, efficient scalar marginals, and approximate backward memorylessness expected of a good long-block code.

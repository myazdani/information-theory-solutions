# Exercise 10.17 — Source-channel separation with allowed distortion

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 344.

## Solution

### (a)
Choose an intermediate rate $`R(D)<R<C`$. A source rate-distortion code at rate $`R`$ achieves expected distortion at most $`D+\delta`$ for sufficiently long blocks. A channel code of that rate conveys its index with vanishing error. For bounded finite-alphabet distortion, a channel decoding error contributes at most $`d_{\max}`$, so the total expected distortion is bounded by
```math
D+\delta+d_{\max}P_{e,\rm channel}.
```
This approaches $`D`$ as closely as desired. Finite alphabets with finite distortion values are the standard setting; unbounded or infinite costs require an additional integrability/error-handling argument rather than this bound.

### (b)
Let $`D_i=\mathbb Ed(V_i,\widehat V_i)`$. Source independence, the scalar rate-distortion bound, convexity, data processing, and the channel capacity bound give
```math
nR(D)\le\sum_i R(D_i)\le\sum_i I(V_i;\widehat V_i)
\le I(V^n;\widehat V^n)\le I(X^n;Y^n)\le nC.
```
Thus the correct converse is $`C\ge R(D)`$. The exercise's phrase “greater than” cannot in general be strict. A noiseless binary channel carrying a fair binary source exactly has $`C=R(0)=1`$. Strict inequality is a sufficient achievability condition; equality depends on the source/channel pair and boundary requirements.

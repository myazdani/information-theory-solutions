# Exercise 10.8 — Variance-based bounds for squared-error compression

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 338–339.

## Solution

Assume $`0<D<\sigma^2`$ and a source density with well-defined entropy. For any reconstruction meeting the distortion budget,
```math
h_2(X\mid\widehat X)=h_2(X-\widehat X\mid\widehat X)
\le h_2(X-\widehat X)\le\tfrac12\log_2(2\pi eD).
```
This proves $`R(D)\ge h_2(X)-\frac12\log_2(2\pi eD)`$, strengthened by taking its maximum with zero.

For the upper bound, let $`Z`$ be independent Gaussian with variance $`D\sigma^2/(\sigma^2-D)`$, and define $`\widehat X=a(X+Z)`$ with $`a=(\sigma^2-D)/\sigma^2`$. Direct computation gives
```math
\mathbb E(X-\widehat X)^2=(1-a)^2\sigma^2+a^2\mathrm{Var}(Z)=D.
```
Scaling is invertible, so
```math
I(X;\widehat X)=I(X;X+Z)
\le\frac12\log_2\left(1+\frac{\sigma^2}{\mathrm{Var}(Z)}\right)
=\frac12\log_2(\sigma^2/D).
```
The inequality is Gaussian maximum entropy at the given output variance. Thus a Gaussian source is hardest to describe among sources of the same variance: it attains this upper bound. At $`D\ge\sigma^2`$, zero reconstruction gives $`R(D)=0`$, so the upper bound must be read with a positive part; the unmodified logarithm would be negative. Endpoint $`D=0`$ is handled by a limit where appropriate.

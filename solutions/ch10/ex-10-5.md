# Exercise 10.5 — Uniform finite-alphabet source under Hamming loss

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 337.

## Solution

Let $`D_0=1-1/m`$, and assume $`m\ge2`$. For a test channel with actual error probability $`d\le D\le D_0`$, the error-indicator argument gives
```math
H(X\mid\widehat X)\le h_2(d)+d\log_2(m-1)
\le h_2(D)+D\log_2(m-1).
```
The second inequality holds because the right-hand function is increasing up to $`D_0`$. Therefore
```math
R(D)\ge\log_2m-h_2(D)-D\log_2(m-1).
```
For equality, take uniform $`\widehat X`$ and the backward channel assigning probability $`1-D`$ to $`X=\widehat X`$ and $`D/(m-1)`$ to each other source symbol. It has the required uniform source marginal, distortion $`D`$, and the asserted conditional entropy. Hence
```math
R(D)=\begin{cases}
\log_2m-h_2(D)-D\log_2(m-1),&0\le D\le1-1/m,\\
0,&D\ge1-1/m.
\end{cases}
```
A fixed reproduction attains the zero-rate branch. For $`m=1`$, the rate is identically zero for nonnegative budgets.

# Exercise 16.6: Distributions sharing an optimal portfolio form a convex set

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed p. 653.

## Solution

Fix $`b_0`$. Let $`p_1,p_2`$ both make $`b_0`$ optimal, and put $`p_\lambda=\lambda p_1+(1-\lambda)p_2`$ for $`0\le\lambda\le1`$. For any competitor $`b`$, linearity of integration gives

```math
W(b_0,p_\lambda)-W(b,p_\lambda)
=\lambda[W(b_0,p_1)-W(b,p_1)]
 +(1-\lambda)[W(b_0,p_2)-W(b,p_2)]\ge0.
```

Thus $`b_0`$ is also optimal under $`p_\lambda`$, proving convexity. This proof assumes the differences are well-defined, for example all relevant expected logs are finite.

An equivalent formulation using the growth-optimality criterion avoids subtracting raw infinite growth rates. Whenever $`b_0^TX>0`$ almost surely, optimality in relative growth is characterized by

```math
\int\frac{x_i}{b_0^Tx}\,p(x)\,dx\le1,\qquad i=1,\ldots,m.
```

These are linear inequalities in $`p`$. Their intersection with the convex set of probability densities is convex, yielding the same result for the normalized definition.

# Exercise 16.5: Exchangeability favors the uniform allocation

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed p. 653.

## Solution

### (a)
Write $`W(b)=E\log(b^TX)`$. This is a concave function on the portfolio simplex. Exchangeability makes it invariant under permuting portfolio coordinates. Averaging a portfolio over all $`m!`$ permutations gives the uniform vector $`u=(1/m,\ldots,1/m)`$. Jensen's inequality therefore gives

```math
W(u)=W\left(\frac1{m!}\sum_\sigma b_\sigma\right)
\ge\frac1{m!}\sum_\sigma W(b_\sigma)=W(b).
```

Thus $`b_*=u`$ is optimal. It need not be uniquely optimal, for example when every asset has the same return almost surely. Assume logarithms are well-defined, or use the relative normalization in Exercise 16.8 in cases of infinite raw growth.

### (b)
Under the additional almost-sure normalization $`m^{-1}\sum_iX_i=1`$, the uniform portfolio's multiplier is exactly 1 for every outcome. Its growth therefore does not depend on the particular symmetric distribution.

### (c)
That common optimal growth is $`W_*=\log1=0`$, in either bits or nats. This uses the stated outcome-by-outcome normalization; imposing only $`E[m^{-1}\sum_iX_i]=1`$ would not give the same conclusion.

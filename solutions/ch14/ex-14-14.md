# Exercise 14.14: Largest describable and smallest undescribable integers

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed p. 507.

## Solution

Assume $`n`$ is large enough that the set of halting outputs is nonempty. The constants below depend on the universal machine.

By definition, $`K(M(n))\le n`$. But $`M(n)+1`$ is not produced by any program of length at most $`n`$, while a program for $`M(n)`$ followed by a fixed increment routine produces it. Hence

```math
n-O(1)\le K(M(n))\le n.
```

For the least omitted integer, $`K(S(n))>n`$ by definition. There are fewer than $`2^{n+1}`$ binary programs of length at most $`n`$, so at least one of the first $`2^{n+1}`$ positive integers is omitted. Thus

```math
S(n)\le2^{n+1},\qquad
n\lt K(S(n))\le n+O(\log n),
```

where the upper bound encodes $`S(n)`$ literally with a self-delimiting length. In a prefix-free program domain, Kraft improves the counting bound to $`S(n)\le2^n+1`$, but the stated first-order complexity is unchanged.

The magnitudes are very different. A program that describes $`n`$ and prints $`2^{2^n}`$ has length $`O(\log n)`$, so for all sufficiently large $`n`$,

```math
M(n)\ge2^{2^n}>2^{n+1}\ge S(n).
```

Indeed, for every fixed total computable function $`g`$, a short description of $`n`$ plus a fixed program for $`g(n)+1`$ shows $`M(n)>g(n)`$ eventually. Thus $`M(n)`$ grows faster than every computable function, while $`S(n)`$ has an elementary exponential upper bound. For tiny $`n`$ the ordering can depend on the universal machine; the comparison here is the requested large-$`n`$ one. Neither can be computed by naively running all short programs to completion, because nonhalting programs cannot in general be recognized.

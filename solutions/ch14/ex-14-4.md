# Exercise 14.4: Infinite entropy from random programs

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed p. 504.

## Solution

Add a special undefined-output symbol for nontermination so that the output law is a probability distribution. Construct a prefix machine $`A`$ that first reads $`k`$ ones followed by a zero, then reads $`2^k`$ further bits, prints those bits, and halts. Under fair random input,

```math
P(K=k)=2^{-(k+1)},\qquad H(X\mid K=k)=2^k.
```

The output length determines $`k`$, so

```math
H_A(X)=H(K)+\sum_{k\ge0}2^{-(k+1)}2^k=\infty.
```

Universality supplies a fixed prefix, of some length $`c`$, that makes $`U`$ simulate $`A`$. Its output law therefore dominates $`2^{-c}P_A`$ pointwise. We may write the full output law as a mixture
$`P_U=2^{-c}P_A+(1-2^{-c})Q`$, including the undefined symbol in $`Q`$. Concavity of Shannon entropy, or conditioning on the mixture selector, yields $`H(P_U)\ge2^{-c}H(P_A)=\infty`$.

If entropy is instead computed conditionally on halting, the same dominated subdistribution survives with a positive rescaled weight, so the entropy is still infinite. A deterministic computer need not increase entropy; it retains enough of the infinite random-input entropy to make this particular output entropy infinite.

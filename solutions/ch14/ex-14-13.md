# Exercise 14.13: Complexity changes under an integer offset

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed p. 507.

## Solution

A program for $`n_1`$ plus a self-delimiting program for the signed offset $`k`$ computes $`n_1+k`$. Conversely, a program for $`n_1+k`$ plus the same offset computes $`n_1`$. Consequently, whenever the relevant integers are in the chosen domain,

```math
|K(n_1+k)-K(n_1)|\le K(k)+O(1).
```

For a fixed $`k`$, the difference is bounded by a constant independent of $`n_1`$. For growing $`|k|\ge2`$, self-delimiting integer coding gives the explicit bound
$`\log_2|k|+2\log_2\log_2|k|+O(1)`$, with a constant-size sign bit. This bound is stronger than saying that numerical closeness forces equal complexity: small offsets limit the change, while a sufficiently complex large offset can make it large. If $`n_1`$ itself is simple, the complexity of the shifted integer is controlled principally by the information in $`k`$.

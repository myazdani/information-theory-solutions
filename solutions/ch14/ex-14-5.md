# Exercise 14.5: Algorithmic probabilities of structured prefixes

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed p. 504.

## Solution

Use the prefix-event interpretation: a program counts when it prints the required initial symbols, whether or not it eventually halts. Multiplicative constants depend on the chosen universal computer, so there are no machine-independent numerical probabilities. Logs and program lengths are binary.

### (a)
A fixed program prints zeros forever. The event therefore has probability at least some constant $`c_0>0`$, independent of $`n`$, and at most 1. Its order is $`\Theta(1)`$, rather than the fair-output probability $`2^{-n}`$.

### (b)
A fixed algorithm computes and prints successive binary digits of $`\pi`$. Thus the same conclusion holds: a machine-dependent probability bounded below by a positive constant independent of $`n`$.

### (c)
Printing exactly $`n`$ initial zeros before the first 1 encodes $`n`$. Conversely a shortest program for $`n`$ can be followed by a fixed routine that prints $`0^n1`$. These mutually exclusive prefix events form a lower-semicomputable discrete semimeasure over $`n`$; the universal coding theorem consequently gives probability $`\Theta(2^{-K(n)})`$. For most integers of size about $`n`$, this is roughly $`1/n`$ if logarithmic self-delimiting factors are suppressed. Exceptionally simple $`n`$ can be much likelier, so $`1/n`$ is not a uniform bound.

### (d)
For the algorithmically random halting-probability sequence $`\omega`$, a length-$`n`$ prefix has probability $`\Theta(2^{-n})`$ under the universal prefix semimeasure. The lower bound comes from simulating fair independent output. For the upper bound, the ratio of the universal prefix semimeasure to fair-cylinder probability is a lower-semicomputable supermartingale; it is bounded along a Martin–Löf random sequence such as $`\omega`$. Equivalently, there is no computable regularity that gives a growing likelihood advantage for these prefixes.

### (e)
A fixed program enumerates formal proofs and stops upon finding a proof of the four-color theorem (in a chosen effective formal system in which it is provable). Thus the probability of printing some valid proof is at least $`2^{-c}`$, where $`c`$ is that program's fixed description length, regardless of the proof's eventual size or running time. For one specifically prescribed proof string $`s`$, the exact-output probability is instead $`\Theta(2^{-K(s)})`$. The distinction between any proof and one particular proof matters.

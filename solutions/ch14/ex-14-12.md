# Exercise 14.12: Description length and a substitution cipher

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed p. 506.

## Solution

Use 27-ary program symbols throughout, as requested.

### (a)
There are $`27!`$ permutations. Indexing one gives
$`K(\pi)\le\lceil\log_{27}(27!)\rceil+O(1)`$; a typical or maximally complex key has this order of complexity. A specially structured key can be simpler. Numerically the leading key size is $`19.587601344259475`$ 27-ary symbols, or $`93.13684082917975`$ bits.

### (b)
A program for the plaintext and the substitution map computes the ciphertext, and the inverse map recovers the plaintext. Therefore

```math
K(y^n)\le n/4+K(\pi)+O(1),\qquad
K(y^n)\ge n/4-K(\pi)-O(1).
```

The customary estimate for an unrelated, complex key is $`n/4+\log_{27}(27!)`$, capped by a literal description of the ciphertext. Since the alphabet is fixed, key overhead is constant in $`n`$; the cipher preserves the leading $`n/4`$ complexity rate. Equality in the upper bound is a heuristic, not a theorem for every plaintext and key.

### (c)
The redundancy is $`1-1/4=3/4`$ 27-ary symbols per plaintext symbol. The usual unicity-distance estimate balances that against the key uncertainty:

```math
n\cdot\frac34\gtrsim\log_{27}(27!),\qquad
n\gtrsim26.116801792345967.
```

Thus roughly **27 characters** is the information-theoretic threshold under a typical-English/random-key model. Complexity alone does not guarantee unique or efficient decoding at that length: unused letters leave parts of the key undetermined, multiple plausible plaintexts may remain, and Kolmogorov complexity is uncomputable. The estimate concerns expected distinguishability of plaintexts rather than a universal decryption algorithm.

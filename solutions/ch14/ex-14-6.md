# Exercise 14.6: Counting short ternary programs

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed p. 504.

## Solution

Program lengths here are measured in ternary symbols.

### (a)
Given the output length $`n`$, a fixed interpreter can read the next $`n`$ ternary input symbols and print them literally. This gives a description of length $`n+c`$, so $`K(x^n\mid n)\le n+c`$. The interpreter does not need an extra description of $`n`$ because it is supplied as side information.

### (b)
There are

```math
\sum_{j=0}^{k-1}3^j=\frac{3^k-1}{2}\lt 3^k
```

ternary programs shorter than $`k`$. For fixed supplied $`n`$, each halting program produces at most one output. Hence fewer than $`3^k`$ binary length-$`n`$ strings can have ternary-program complexity less than $`k`$. The same counting bound holds even if the output alphabet is all of $`\{0,1,2\}`$ rather than its binary subset.

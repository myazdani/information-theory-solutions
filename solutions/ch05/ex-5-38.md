# Exercise 5.38: Two Huffman alphabets for six symbols

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 155. Logarithms are base 2 unless explicitly written as ln.

## Solution

Use integer weights $`(6,6,4,4,3,2)`$ over 25, with symbols in that order.

## (a)
Binary merges are $`2+3=5`$, $`4+4=8`$, $`5+6=11`$, $`6+8=14`$, and $`11+14=25`$. One code is $`(01,10,110,111,001,000)`$. Its length vector is $`(2,2,3,3,3,3)`$, with mean
```math
L_2=\frac{6\cdot2+6\cdot2+4\cdot3+4\cdot3+3\cdot3+2\cdot3}{25}
=\frac{63}{25}=2.52.
```

## (b)
Add a zero-weight dummy. The quaternary merges are $`0+2+3+4=9`$ and $`4+6+6+9=25`$. A code is $`(1,2,33,0,32,31)`$. Its lengths are $`(1,1,2,1,2,2)`$, with mean
```math
L_4=\frac{6+6+8+4+6+4}{25}=\frac{34}{25}=1.36
```
quaternary digits. Interchanging equal-probability symbols gives equivalent optimal codes.

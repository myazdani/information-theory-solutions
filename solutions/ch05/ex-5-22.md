# Exercise 5.22: Continuity of the optimal mean length

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 148. Logarithms are base 2 unless explicitly written as ln.

## Solution

Fix a finite source alphabet of size $`m\ge2`$ and a code alphabet of size $`D\ge2`$. In seeking an optimum, remove all unary internal nodes of a prefix tree, since contracting one cannot increase any codeword length. Every remaining internal node has at least two children. A root-to-leaf path then has length at most $`m-1`$, because each internal node on the path has another descendant leaf off that path.

Consequently a finite set $`\mathcal L`$ of length vectors contains an optimum for every distribution on this alphabet. Each candidate expected length $`p\mapsto p\cdot\ell`$ is linear and continuous, so their finite minimum
```math
L(p)=\min_{\ell\in\mathcal L}p\cdot\ell
```
is continuous, including at boundary distributions. More quantitatively,
```math
|L(p)-L(q)|\le\max_{\ell\in\mathcal L}|(p-q)\cdot\ell|
\le(m-1)\|p-q\|_1.
```
The optimal tree may switch abruptly at ties, but its minimum value remains continuous. The singleton case is constant under either the empty-word or compulsory-one-symbol convention.

# Exercise 5.21: Equal-block injectivity implies unique decoding

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 148. Logarithms are base 2 unless explicitly written as ln.

## Solution

The forward implication is immediate. For the converse assume all codewords have positive length, as in the usual coding convention, and suppose two distinct finite source strings $`u,v`$ have the same encoded string. Remove any common initial source symbols. The remaining source strings are both nonempty: otherwise one nonempty string would encode to the empty string, impossible with positive codeword lengths. Their first source symbols are different, and their encoded strings still agree, say with common value $`w`$.

Now the source strings $`uv`$ and $`vu`$ have the same number $`|u|+|v|`$ of symbols and different first symbols, but both encode to $`ww`$. This contradicts injectivity of the extension at that fixed block length. Thus no ambiguity can exist.

The nonempty-codeword convention is necessary in the degenerate one-symbol case: assigning the empty word to its sole symbol makes every fixed-length extension trivially injective, while different source lengths cannot be distinguished.

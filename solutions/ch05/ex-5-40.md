# Exercise 5.40: Rates of three encoded bitstreams

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 156. Logarithms are base 2 unless explicitly written as ln.

## Solution

The iid source has entropy rate $`H(X)=H(1/2,1/4,1/4)=3/2`$ bits per source symbol.

## (a)
For code $`(0,10,11)`$, its mean length is $`3/2`$, matching the source entropy. At the root, the two branches have probabilities $`1/2,1/2`$, and after branch 1 its two leaves are equiprobable. Successive source symbols are independent, so the concatenated bits are iid fair and have rate 1 bit per output bit.

## (b)
Code $`(00,10,01)`$ is a fixed-length, injective two-bit code. A block of $`2n`$ output bits has exactly the entropy of $`n`$ input symbols, namely $`3n/2`$. An odd final output bit changes entropy by at most one. Therefore the output entropy rate is $`(3/2)/2=3/4`$ bit per output bit.

## (c)
As printed, the code is $`(00,1,01)`$. It is prefix-free and has mean length $`2(1/2)+1(1/4)+2(1/4)=7/4`$. Its output entropy rate is
```math
h(Z)=\frac{H(X)}{\mathbb E\ell(X)}=\frac{3/2}{7/4}=\frac67\ \text{bit per output bit}.
```
For justification of the variable-length rate formula here, a length-$`N`$ output prefix comprises some complete source codewords followed by at most one incomplete word. Prefix decoding identifies those complete words. The probability of the bit prefix equals the product of their source probabilities times a final subtree probability. Since this finite code has positive leaf masses and bounded lengths, that last factor contributes only a bounded log-probability correction. The renewal law gives complete-word count divided by $`N`$ tending to $`1/\mathbb E\ell`$, and the law of large numbers for source surprisals gives the displayed rate. Bounded per-bit surprisals permit expectation limits as well. The known starting boundary changes only a finite-edge effect, not the entropy rate.

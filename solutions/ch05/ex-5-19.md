# Exercise 5.19: Optimal guessing with rewards and costs

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 147. Logarithms are base 2 unless explicitly written as ln.

## Solution

Put $`w_i=p(i)v(i)`$. In (a), comparisons reveal an interval containing the true index; in (b), arbitrary subset questions are allowed.

## (a)
Use interval dynamic programming. Let $`F(a,b,k)`$ be the maximum unnormalized expected prize from indices $`a,\ldots,b`$ with $`k`$ guesses left. Set $`F(a,b,0)=0`$ and $`F(a,b,k)=0`$ when $`a>b`$. For $`k\ge1`$,
```math
F(a,b,k)=\max_{a\le j\le b}
\{w_j+F(a,j-1,k-1)+F(j+1,b,k-1)\}.
```
Guess an index attaining the maximum, and after a high/low answer use the stored optimal rule for the corresponding subinterval. The initial value is $`F(1,100,6)`$. The formula adds the reward when correct and the two disjoint continuation cases. Induction on $`k`$ proves optimality. Unnormalized masses avoid repeated Bayes normalizations; they do not change a conditional choice within an interval.

## (b)
The expected prize $`\sum_ip_iv_i`$ is fixed because questioning continues until identification. Therefore maximize payoff by minimizing the expected number of questions: use a binary Huffman decision tree for $`p`$. The exact expected payoff is
```math
R(p)=\sum_ip_iv_i-L_H(p).
```
Each tree split is implemented by asking whether the object lies among one child node's leaves.

## (c)
For exact integer-length coding this is a finite convex, piecewise-linear optimization problem; an entropy relaxation alone does not generally give its exact answer. The following finite linear program determines the computer's optimal distribution and the exact expected return for every given reward vector.

Let $`\mathcal L_m`$ be all labeled length vectors of full binary prefix trees with $`m=100`$ leaves. They can be enumerated by all full binary tree shapes and all assignments of the labels. Every such depth is at most $`m-1`$, so this is a finite set. Solve
```math
\begin{aligned}
\text{minimize }&t\\
\text{over }&p_i\ge0,\quad\sum_i p_i=1,\\
\text{subject to }&t\ge\sum_i p_i(v_i-\ell_i)
\quad\text{for every }\ell\in\mathcal L_m.
\end{aligned}
```
The computer chooses an optimal $`p^*`$ and the player's expected return is the optimum $`t^*`$. This is exact because
```math
\max_{\ell\in\mathcal L_m}\sum_ip_i(v_i-\ell_i)
=\sum_ip_iv_i-\min_{\ell\in\mathcal L_m}\sum_ip_i\ell_i=R(p).
```
Full trees suffice because contracting a unary branch never increases expected cost. A separation oracle for the LP is simply Huffman coding of its candidate $`p`$: it finds the most violated constraint. Thus exhaustive tree enumeration is not necessary to implement the specification.

For an equivalent optimality certificate, there must be a mixture of Huffman-optimal length vectors at $`p^*`$ such that $`v_i-\mathbb E\ell_i=t^*`$ on every positive-$`p_i^*`$ coordinate and is at least $`t^*`$ on the others. This is the finite-game minimax dual, or the subgradient condition for minimizing $`R`$ on the simplex.

The useful closed-form relaxation is obtained by setting $`Z=\sum_i2^{-v_i}`$ and $`q_i=2^{-v_i}/Z`$. Since
```math
\sum_ip_iv_i-H(p)=D(p\Vert q)-\log_2Z,
```
Gibbs' inequality shows that $`q`$ minimizes the real-length version. The integer-code bounds imply
```math
-\log_2Z-1\le\min_pR(p)\le R(q)\le-\log_2Z.
```
Thus $`q`$ is within one unit of exact minimax optimality, but need not be the exact optimizer. For example, with two retained alphabet symbols of rewards $`v_1<v_2`$, every optimal binary code has lengths 1,1; the exact minimizer is $`p=(1,0)`$, with return $`v_1-1`$, rather than the strictly positive Gibbs law.

The LP follows the fixed-alphabet coding convention: even a zero-probability symbol retains a codeword. For the alternative interpretation in which the player discards impossible outcomes, an exact support-aware procedure is as follows. For every nonempty support $`S`$, solve the same closed-simplex LP using only code trees on $`S`$; its optimum $`t_S`$ is the infimum over distributions strictly positive on that support, by continuity. Test whether this value is attained within that support by maximizing $`\delta`$ subject to the LP constraints, $`t=t_S`$, and $`p_i\ge\delta`$ for every $`i\in S`$. A positive maximum $`\delta`$ means that $`t_S`$ is attained with exactly that support; otherwise it is only approached from its interior. A singleton support uses zero questions and has value equal to its sole prize. The global infimum is $`\min_{S\ne\varnothing}t_S`$. A minimizing distribution exists precisely when some support attaining that smallest value passes the positive-$`\delta`$ test. Otherwise the computer can approach that value arbitrarily closely but no optimal announced distribution exists. Thus the boundary convention can genuinely change the existence and value of the answer.

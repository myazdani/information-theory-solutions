# Exercise 5.20: Huffman coding with symbol-dependent costs

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 147–148. Logarithms are base 2 unless explicitly written as ln.

## Solution

Assume first that $`a_i=p_ic_i>0`$ and put $`A=\sum_i a_i`$, $`q_i=a_i/A`$.

## (a)
For real lengths, set $`K=\sum_i2^{-\ell_i}\le1`$ and $`r_i=2^{-\ell_i}/K`$. Then
```math
C=A\sum_iq_i\ell_i=A[H(q)+D(q\Vert r)-\log_2K]\ge AH(q).
```
Equality is attained at $`\ell_i^*=-\log_2q_i=\log_2(A/(p_ic_i))`$, for which Kraft equality holds. Thus $`C^*=AH(q)`$.

## (b)
Run binary Huffman coding on the normalized weights $`q_i`$, or equivalently directly on $`p_ic_i`$. Since $`C=A\sum_iq_i\ell_i`$, minimizing that ordinary mean length is exactly the desired cost minimization. McMillan and Kraft ensure the same optimum over uniquely decodable and prefix codes.

## (c)
The real relaxation is a lower bound, and Shannon lengths $`\lceil-\log_2q_i\rceil`$ have cost less than $`A(H(q)+1)`$. Therefore
```math
C^*\le C_{\rm Huffman}\lt C^*+A,
```
which implies the requested non-strict upper bound. If some weights vanish, Huffman can include zero-weight leaves and the non-strict bound follows by a positive-weight limiting argument. The real-length value is then an infimum if zero-weight symbols must retain finite codewords; discard such symbols only when the code's scope permits it. If every weight is zero, every code has cost zero.

# Exercise 5.16: Binary coding versus paired quaternary digits

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 146. Logarithms are base 2 unless explicitly written as ln.

## Solution

## (a)
With source symbols $`A,B,C,D,E,F`$ in order, one binary Huffman code is $`(0,10,1111,1100,1101,1110)`$. Its lengths are $`(1,2,4,4,4,4)`$ and its mean is 2 bits. Valid alternative tie choices can give different optimal length vectors.

## (b)
Add one zero-probability dummy to make seven leaves, which is $`1\pmod3`$. Using letters $`a,b,c,d`$ for digits 0,1,2,3, one quaternary code is $`(d,c,a,bb,bc,bd)`$. It comes from merging the dummy and the three 0.05 symbols, then merging the resulting 0.15 node with 0.1,0.25,0.5. Its mean is $`0.5+0.25+0.1+2(0.15)=23/20`$ quaternary digits.

## (c)
Replacing each quaternary digit by its two-bit representation yields a binary prefix code of mean $`2(23/20)=23/10=2.3`$ bits.

## (d)
This transformed code is a candidate binary prefix code, so $`L_H\le L_{QB}`$. The quaternary entropy bound gives
```math
L_{QB}=2L_4\lt 2(H_4(X)+1)=H_2(X)+2\le L_H+2.
```

## (e)
For four equiprobable symbols, the quaternary optimum uses one digit each. Its two-bit representation is the optimal two-bit fixed-length binary code, so $`L_{QB}=L_H=2`$.

## (f)
Let $`\ell_i`$ be optimal binary lengths. The integer lengths $`m_i=\lceil\ell_i/2\rceil`$ satisfy
```math
\sum_i4^{-m_i}\le\sum_i2^{-\ell_i}\le1,
```
so a quaternary prefix code with these lengths exists. Optimality in the quaternary problem implies
```math
L_{QB}\le2\sum_ip_i\left\lceil\frac{\ell_i}{2}\right\rceil
\le\sum_ip_i(\ell_i+1)=L_H+1.
```
For any nondegenerate two-symbol distribution, the binary Huffman code has mean 1 and the quaternary Huffman code also has one digit per symbol. Converting it yields mean 2, attaining the additive gap 1.

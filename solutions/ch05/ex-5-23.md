# Exercise 5.23: Completeness and decoding delay

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 148. Logarithms are base 2 unless explicitly written as ln.

## Solution

Use the chapter's finite-codebook convention and nonempty codewords.

## (a)
Let the output alphabet have size $`D`$, and view finite strings as cylinders in an infinite iid uniform output sequence. The cylinder for a word $`c`$ has probability $`D^{-|c|}`$. Kraft equality says the sum of the individual cylinder probabilities is 1. Since the code is not prefix-free, at least two cylinders overlap with positive probability; therefore the probability of their union is strictly less than 1.

The union is a finite union of cylinders. Its complement contains a cylinder $`[w]`$ for some finite word $`w`$ (one may take the common depth to be the largest codeword length). No codeword is a prefix of $`w`$, and no codeword has $`w`$ as a prefix. Every nonempty concatenation begins with a codeword, so $`w`$ cannot be the prefix of any such concatenation.

## (b)
If the code is not uniquely decodable, some finite string already has two source interpretations; appending the same infinite sequence of codewords preserves that ambiguity. There is no unique decoder, so a finite guaranteed deciphering delay is impossible.

For the uniquely decodable case, apply the finite maximal-code theorem of Schützenberger: a finite maximal uniquely decodable code with finite deciphering delay is a prefix code. Here maximality follows immediately from Kraft equality and McMillan's inequality. Indeed, adjoining any new finite word would increase the Kraft sum above 1, so the enlarged code could not remain uniquely decodable. If this nonprefix code had finite deciphering delay, the theorem would force it to be prefix, a contradiction. It therefore has infinite deciphering delay: no uniform finite lookahead resolves the first codeword in every encoded continuation.

This argument uses finiteness of the codebook. The theorem is a standard result beyond the elementary Kraft inequality; an authoritative statement and proof reference is Berstel, Perrin, and Reutenauer, *Codes and Automata*, chapter [Deciphering Delay](https://www.cambridge.org/core/books/abs/codes-and-automata/deciphering-delay/00F3E2DB35E16C4643161D9E016573F5). It is not an assertion that every countably infinite complete nonprefix code has the same property.

# Exercise 5.32: Sequential and pooled wine tests

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 153–154. Logarithms are base 2 unless explicitly written as ln.

## Solution

Assume a mixture tests bad exactly when it contains the unique bad bottle. Number the bottles in the printed order with integer weights $`(8,6,4,2,2,1)`$ over 23.

## (first.a)
For individual sequential tasting, the number of tastings associated with the six tested positions is $`(1,2,3,4,5,5)`$, since the sixth bottle is inferred after five clean tests. An exchange argument assigns larger probabilities to smaller tasting counts, so descending probability order is optimal. Its expectation is
```math
\frac{8\cdot1+6\cdot2+4\cdot3+2\cdot4+2\cdot5+1\cdot5}{23}
=\frac{55}{23}\approx2.3913043478.
```

## (first.b)
Taste bottle 1, whose bad probability is $`8/23`$, first. Ties among the two weight-2 bottles and the equal final tasting counts do not affect the optimum.

## (second.a)
Pooling allows arbitrary subset yes/no tests, so the optimal decision tree is Huffman's. The successive merges of integer weights are $`1+2=3`$, $`2+3=5`$, $`4+5=9`$, $`6+8=14`$, and $`9+14=23`$. A code is $`(11,10,00,0111,010,0110)`$, with lengths $`(2,2,2,4,3,4)`$. The minimum expected number of tastings is
```math
\frac{8\cdot2+6\cdot2+4\cdot2+2\cdot4+2\cdot3+1\cdot4}{23}
=\frac{54}{23}\approx2.3478260870.
```

## (second.b)
The root separates the weight-14 group $`\{1,2\}`$ from the weight-9 group $`\{3,4,5,6\}`$. Taste a mixture of bottles 1 and 2 first; the result identifies which group contains the bad bottle. Tasting the complementary group is equivalent. Follow the indicated Huffman subtree for subsequent mixtures.

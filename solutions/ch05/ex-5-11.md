# Exercise 5.11: Suffix-free codes and reversal

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 145. Logarithms are base 2 unless explicitly written as ln.

## Solution

A finite string encoded with a suffix-free code can be decoded from right to left: the final codeword is determined without ambiguity, and the argument repeats after deleting it. Thus the code is uniquely decodable.

More generally, reversing every individual codeword converts a suffix-free code into a prefix-free code, and conversely. Reversal preserves each length, hence every expected length. The two optimization problems therefore have identical feasible length objectives. The optimum for suffix-free codes is attained by reversing a Huffman prefix code and equals the Huffman mean length.

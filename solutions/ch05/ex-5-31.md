# Exercise 5.31: The advantage of a one-to-one code

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 152–153. Logarithms are base 2 unless explicitly written as ln.

## Solution

Use the question's nonempty binary codeword convention and decreasing probability order.

## (a)
Append a STOP symbol to each distinct binary codeword. The resulting words over $`\{0,1,\mathrm{STOP}\}`$ are prefix-free: a STOP ending one word cannot occur inside another's binary portion. Their mean ternary length is $`L_{1:1}+1`$. The ternary entropy bound gives
```math
L_{1:1}+1\ge H_3(X)=\frac{H_2(X)}{\log_23},
```
which is the requested inequality.

## (b)
Every instantaneous code is nonsingular, so minimizing over all nonsingular codes can only reduce mean length. The ordinary source-coding bound yields
```math
L_{1:1}^*\le L_{\rm INST}^*\le H_2(X)+1.
```

## (c)
For three equally likely symbols, the code $`0,1,00`$ is nonsingular and has mean $`4/3<\log_23`$. Its endpoint is assumed observable, so concatenation ambiguity is irrelevant to this one-symbol task.

## (d)
If $`p_i>p_j`$ but $`\ell_i>\ell_j`$, exchanging the two codewords changes cost by $`-(p_i-p_j)(\ell_i-\ell_j)<0`$. Hence shortest available words must go to the most probable symbols. There are $`2^j`$ binary words of length $`j`$ and $`2^{j+1}-2`$ nonempty words of length at most $`j`$. Thus
```math
\ell_i=\left\lceil\log_2\left(\frac i2+1\right)\right\rceil
=\lfloor\log_2(i+1)\rfloor,
\qquad L_{1:1}^*=\sum_{i=1}^mp_i\left\lceil\log_2\left(\frac i2+1\right)\right\rceil.
```

## (e)
Set $`S=\sum_{i=1}^m1/(i+2)=\mathcal H_{m+2}-\mathcal H_2`$ and $`q_i=1/[S(i+2)]`$. The unrounded length lower bound is $`\widetilde L=\sum_ip_i\log_2((i+2)/2)`$. Then
```math
F(p)=H(p)-\widetilde L=\log_2(2S)-D(p\Vert q).
```
It is maximized uniquely at $`p=q`$, which respects the decreasing-order constraint. Equivalently, a Lagrange multiplier for $`\sum_ip_i=1`$ gives $`-\log_2p_i-1/\ln2-\log_2((i+2)/2)=\lambda`$, hence $`p_i=c/(i+2)`$ with $`c=1/S`$; strict concavity proves this stationary point is the global maximum.

## (f)
Since rounded lengths dominate their unrounded values,
```math
H(p)-L_{1:1}^*\le H(p)-\widetilde L\le\log_2(2S).
```
For $`m\ge2`$, integration bounds
```math
S=\sum_{j=3}^{m+2}\frac1j\le\int_2^{m+2}\frac{dx}{x}
=\ln\frac{m+2}{2}\le\ln m.
```
In particular $`\log_2(2S)\le\log_2\log_2m+\log_2(2\ln2)<\log_2\log_2m+2`$. Together with (b), this proves
```math
H(p)-\log_2\log_2m-2\le L_{1:1}^*\le H(p)+1.
```
For $`m=1`$ the logarithm-of-logarithm expression is not defined and should be omitted; the direct one-symbol result is immediate.

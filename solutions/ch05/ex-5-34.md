# Exercise 5.34: A minimum-delay binary combining tree

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 154–155. Logarithms are base 2 unless explicitly written as ln.

## Solution

## (a)
A full binary gate tree computes the associative sum with its inputs at the leaves. There is an optimal tree whose two earliest inputs occupy deepest sibling leaves. To prove this, take any deepest sibling pair. Move the smallest arrival times to those positions by exchanges: if an earlier arrival $`T_a\le T_b`$ is on a shallower leaf of depth $`d_a\le d_b`$, swapping them cannot increase the largest arrival-plus-depth value, because both new sums are at most $`T_b+d_b`$ or the previous maximum. Make this exchange for the two earliest arrivals and the sibling pair.

Now contract the pair into a single pseudo-input available at $`\max(T_1,T_2)+1`$. Its effect on all later gate times is exactly the effect of that merged node. An optimal solution to the reduced problem therefore extends to an optimal solution of the original. Induction proves the greedy algorithm that repeatedly combines the two earliest currently available values.

## (b)
Along the path of input $`i`$, exactly $`\ell_i`$ unit-delay gates must be traversed. Induction through the gate recurrence $`T_{\rm out}=\max(T_{\rm left},T_{\rm right})+1`$ shows that the root time is exactly $`\max_i(T_i+\ell_i)`$. Thus (a) minimizes the stated tree functional.

## (c)
For any prefix-tree lengths with completion time $`C`$, $`T_i+\ell_i\le C`$. Hence
```math
\sum_i2^{T_i}\le2^C\sum_i2^{-\ell_i}\le2^C,
\qquad C\ge\log_2\sum_i2^{T_i}.
```

## (d)
Let $`S=\sum_i2^{T_i}`$ and choose integer lengths $`\ell_i=\lceil\log_2(S/2^{T_i})\rceil`$. They satisfy Kraft's inequality since $`2^{-\ell_i}\le2^{T_i}/S`$. A prefix tree with these lengths exists, and
```math
T_i+\ell_i\lt \log_2S+1\quad\text{for every }i.
```
Contracting any unary nodes turns it into a full gate tree and only reduces completion time. Therefore some gate tree has $`C\le\log_2S+1`$ (indeed a strict inequality except harmless conventions). The singleton-input case has $`C=T_1`$ directly.

# Exercise 5.1: A nonlinear objective for code lengths

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 142. Logarithms are base 2 unless explicitly written as ln.

## Solution

Every instantaneous code is uniquely decodable, so minimizing over the larger class gives $`L_2\le L_1`$. Conversely the lengths of any uniquely decodable $`D`$-ary code satisfy McMillan's inequality. Kraft's converse constructs an instantaneous code with exactly the same lengths. Its objective $`\sum_ip_i\ell_i^{100}`$ is therefore unchanged. Hence $`L_1\le L_2`$ and the two minima are equal. The argument applies to any objective depending only on the length vector, not just mean length.

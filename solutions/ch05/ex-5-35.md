# Exercise 5.35: Generating a biased bit from fair bits

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 155. Logarithms are base 2 unless explicitly written as ln.

## Solution

Interpret the iid fair bits as the binary expansion of a uniform random number $`U=0.Z_1Z_2\cdots`$ on $`[0,1]`$. We want output 1 exactly when $`U<p`$.

After $`n`$ flips, the observed prefix identifies a dyadic half-open interval of length $`2^{-n}`$. If that entire interval is below $`p`$, output 1; if it is above $`p`$, output 0; otherwise request another bit. Endpoints of measure zero can be settled arbitrarily. At most one depth-$`n`$ interval straddles the threshold, so
```math
\Pr(N>n)\le2^{-n},\qquad
\mathbb EN=\sum_{n=0}^\infty\Pr(N>n)\le\sum_{n=0}^\infty2^{-n}=2.
```
The algorithm terminates almost surely and returns a Bernoulli($`p`$) variable because $`\Pr(U<p)=p`$. For $`p=0`$ or 1 no flips are needed; for a dyadic threshold it stops within a finite number of bits. For a nondyadic threshold the bound is attained, since exactly one interval remains ambiguous at every depth.

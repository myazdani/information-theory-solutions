# Exercise 5.29: Why an entropy-achieving code emits fair bits

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 151. Logarithms are base 2 unless explicitly written as ln.

## Solution

Assume a finite dyadic distribution with positive masses and omit the deterministic singleton case when discussing an infinite output stream.

## (a)
The lengths $`-\log_2p_i`$ are integers with Kraft sum 1, so an entropy-achieving binary prefix code exists. A Huffman code is optimal, so it too has mean length exactly $`H(p)`$. Equality in the coding bound forces $`p_i=2^{-\ell_i}`$. The Huffman tree is full. For a node at depth $`d`$, completeness of its subtree gives
```math
\Pr(\text{node})=\sum_{i\text{ below node}}2^{-\ell_i}=2^{-d}.
```
Each child at depth $`d+1`$ therefore has mass $`2^{-(d+1)}`$, half the parent's mass.

## (b)
Consider concatenating the codes of an infinite iid source sequence. Given all emitted bits so far, the decoder knows its current tree node (and whether a new codeword is starting). At an internal node, part (a) makes either next branch equally likely. At a fresh root, the next independent source symbol has the original law, so the same statement holds. Therefore each next bit is fair conditional on every previous output prefix; all finite bit prefixes have probability $`2^{-k}`$. The output bits are iid Bernoulli($`1/2`$) and have entropy rate 1 bit per output bit.

For a finite block of $`n`$ input symbols, its output stops at a random boundary. One must not additionally condition on its final length and then infer unrestricted iid bits: that stopping condition can introduce selection effects. The assertion about entropy rate concerns the ongoing concatenated stream.

## (c)
If an entropy-achieving lossless code produced a stream compressible by a positive asymptotic fraction, composing the two compressors would give a lossless source description below its entropy rate. That contradicts the entropy lower bound. Thus, after boundary overhead is negligible, an entropy-achieving binary output stream must have full one-bit entropy rate. Part (b) supplies a rigorous iid version for dyadic Huffman coding.

# Exercise 5.14: Huffman codes for six rational masses

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 145–146. Logarithms are base 2 unless explicitly written as ln.

## Solution

Use source indices 1 through 6 and weights $`(1,2,3,4,5,6)`$ before normalization by 21.

## (a)
A binary code is $`(1110,1111,110,00,01,10)`$. The merges are $`1+2=3`$, $`3+3=6`$, $`4+5=9`$, $`6+6=12`$, $`9+12=21`$, so the lengths are $`(4,4,3,2,2,2)`$.

## (b)
Add one zero-weight dummy leaf so that the leaf count is odd, as required for a full ternary tree. The three-way merges are $`0+1+2=3`$, $`3+3+4=10`$, $`5+6+10=21`$. Deleting the dummy from the transmitted alphabet gives the code $`(211,212,20,22,0,1)`$, with lengths $`(3,3,2,2,1,1)`$.

## (c)
The mean lengths are
```math
L_2=\frac{4+8+9+8+10+12}{21}=\frac{17}{7},
\qquad L_3=\frac{3+6+6+8+5+6}{21}=\frac{34}{21}.
```
Units are binary bits and ternary digits respectively; they should not be compared without accounting for alphabet size.

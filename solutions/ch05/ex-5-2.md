# Exercise 5.2: How large must the code alphabet be?

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 143. Logarithms are base 2 unless explicitly written as ln.

## Solution

McMillan's inequality requires
```math
\frac2D+\frac2{D^2}+\frac2{D^3}\le1.
```
For $`D=2`$ the left side is $`7/4>1`$. For $`D=3`$ it is $`26/27<1`$. Thus the sharp integer lower bound is $`D\ge3`$. It is achievable: the ternary codewords 0, 1, 20, 220, 21, 221 have the specified lengths and are prefix-free. The title alludes to the radix, or number of available digits, that a numeral-writing Martian might use.

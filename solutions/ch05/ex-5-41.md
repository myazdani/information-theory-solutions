# Exercise 5.41: Splitting the least likely symbol

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 156–157. Logarithms are base 2 unless explicitly written as ln.

## Solution

Both split masses $`\alpha p_{10}`$ and $`(1-\alpha)p_{10}`$ are at most $`p_{10}`$, which is no larger than any of the first nine masses. A valid Huffman tie-breaking rule can therefore merge these two masses first. Their merged mass is exactly $`p_{10}`$, leaving the original ten-symbol Huffman problem.

Consequently an optimal eleven-symbol code is obtained by retaining the first nine codewords and appending 0 and 1 to the old tenth codeword. Its lengths are
```math
\widetilde\ell_i=\ell_i\ (1\le i\le9),\qquad
\widetilde\ell_{10}=\widetilde\ell_{11}=\ell_{10}+1.
```
The new optimum mean is $`L_{11}^*=L_{10}^*+p_{10}`$, independently of $`\alpha`$. This is an existence statement about an optimal length assignment; other optimal vectors can occur through ties. At $`\alpha=0`$ or 1 the same statement uses the fixed eleven-symbol alphabet including the zero-probability leaf. If impossible symbols are removed instead, one recovers the original ten-symbol coding problem.

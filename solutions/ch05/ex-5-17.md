# Exercise 5.17: Optimal finite and geometric-source lengths

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 146. Logarithms are base 2 unless explicitly written as ln.

## Solution

## (a)
For weights $`(10,9,8,7,7)`$, Huffman merges are $`7+7=14`$, $`8+9=17`$, $`10+14=24`$, and $`17+24=41`$. The optimal lengths are $`(2,2,2,3,3)`$, attained for example by $`(10,01,00,110,111)`$. Their average is $`96/41`$.

## (b)
Index the probabilities as $`p_i=0.9(0.1)^{i-1}`$, $`i\ge1`$. The unary prefix code $`0,10,110,\ldots`$ has lengths $`\ell_i=i`$ and mean
```math
L=0.9\sum_{i\ge1}i(0.1)^{i-1}=\frac{10}{9}.
```
For optimality, any prefix code with $`\ell_1\ge2`$ has mean at least $`2(0.9)+1(0.1)=1.9`$, already worse. If $`\ell_1=1`$, every other word begins with the other bit. Removing that bit gives a prefix code for the conditional tail, whose probability vector is again $`(0.9,0.09,\ldots)`$. Thus its mean obeys $`L=1+0.1L_{\rm tail}`$. Iterating the lower-bound argument proves, for every code and every $`N`$,
```math
L\ge1+0.1+\cdots+(0.1)^{N-1}.
```
Indeed the competing $`\ell_1\ge2`$ case exceeds every such partial sum; otherwise apply induction to the tail code. Letting $`N\to\infty`$ gives $`L\ge10/9`$. The displayed unary code attains this bound.

# Exercise 5.7: Questions that identify all defective objects

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 143–144. Logarithms are base 2 unless explicitly written as ln.

## Solution

The outcome vector $`X^n`$ is the object being identified. A binary decision tree is a prefix code for that vector.

## (a)
Its entropy is $`H(X^n)=\sum_{i=1}^nh_2(p_i)`$ by independence. This is a lower bound on the minimum expected number of questions.

## (b)
An optimal Huffman design can place the two least likely configurations as deepest sibling leaves. Because every $`p_i>1/2`$, the least likely configuration has every object defective. Changing just object $`i`$ to good multiplies its probability by $`p_i/(1-p_i)`$. These ratios decrease with $`i`$, so the second-least likely configuration has only object $`n`$ good. The final question on this deepest branch is therefore whether object $`n`$ is good, distinguishing all defective from all defective except object $`n`$. If other deepest branches exist, their final questions need not be identical; this describes the optimal sibling arrangement for the two least likely outcomes.

## (c)
A Huffman or Shannon decision tree achieves
```math
\sum_i h_2(p_i)\le L_*\lt \sum_i h_2(p_i)+1.
```
Questions may test arbitrary sets of full configurations, so every prefix-code split is admissible.

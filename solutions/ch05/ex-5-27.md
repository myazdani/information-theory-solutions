# Exercise 5.27: The Sardinas–Patterson residual test

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 149–150. Logarithms are base 2 unless explicitly written as ln.

## Solution

Assume a finite nonsingular code with nonempty codewords; duplicate codewords are already an ambiguity.

## (a)
Initialize $`S`$ with all nonempty residuals $`u`$ for which distinct codewords satisfy $`a u=b`$. Repeatedly compare each current residual $`u`$ with every codeword $`c`$: if $`u v=c`$ or $`c v=u`$ for a nonempty residual $`v`$, add $`v`$. Continue to closure. If any residual equals a codeword, cancellation finishes with an empty residual, proving nonunique decoding. If closure contains no codeword, the code is uniquely decodable.

Correctness follows by tracing the unmatched suffix after greedily cancelling the shorter of two partially matched encodings. Any finite ambiguity starts with a prefix relation between different first codewords, passes through exactly these residual transitions, and ends when a residual equals a codeword. Conversely every transition carries a pair of partially matched source strings, so reaching a codeword constructs a finite ambiguity.

## (b)
Every generated residual is a nonempty proper suffix of some original codeword. Thus
```math
|S|\le\sum_{i=1}^m(\ell_i-1).
```
Duplicates reduce the actual size. A sharper alphabet-aware bound is $`\sum_{j\ge1}\min(D^j,\#\{i:\ell_i>j\})`$. The finite bound ensures that closure computation terminates.

## (c.i)
$`\{0,10,11\}`$ is prefix-free, hence uniquely decodable. Its residual set is empty.

## (c.ii)
$`\{0,01,11\}`$ is uniquely decodable. Its residual closure is $`\{1\}`$, containing no codeword.

## (c.iii)
$`\{0,01,10\}`$ is not uniquely decodable: 010 equals both $`0\,10`$ and $`01\,0`$. The residual 1 generates residual 0, a codeword.

## (c.iv)
$`\{0,01\}`$ is uniquely decodable. The only residual is 1, which has no further transitions and is not a codeword.

## (c.v)
$`\{00,01,10,11\}`$ is fixed-length, hence prefix-free and uniquely decodable.

## (c.vi)
$`\{110,11,10\}`$ is uniquely decodable. Its only residual is 0, which has no further transitions and is not a codeword.

## (c.vii)
$`\{110,11,100,00,10\}`$ is uniquely decodable. Its residual closure is $`\{0\}`$; the comparison with 00 returns the same residual but never reaches a codeword.

## (d)
For (ii), the infinite string consisting of a 0 followed by all ones has two parses:
```math
0\mid11\mid11\mid\cdots\quad\text{and}\quad01\mid11\mid11\mid\cdots.
```
For (vii), the infinite string 11 followed by all zeros has two parses:
```math
11\mid00\mid00\mid\cdots\quad\text{and}\quad110\mid00\mid00\mid\cdots.
```
For (iv) and (vi), every nonempty residual is a dead end: after choosing different possible first words, there is no infinite valid continuation on both sides. Hence no such infinite ambiguity exists. For the prefix codes (i) and (v), any two putative parses must have the same first codeword, because two distinct codewords cannot both prefix the same infinite string; deleting it and repeating proves agreement at every boundary. These examples distinguish unique decoding of finite completed messages from finite lookahead on an unending stream.

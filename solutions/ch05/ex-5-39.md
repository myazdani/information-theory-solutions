# Exercise 5.39: Entropy of one codeword and of a concatenation

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 156. Logarithms are base 2 unless explicitly written as ln.

## Solution

## (a)
Because the single-symbol code is nonsingular, $`C(X)`$ determines $`X`$ and vice versa. Hence $`H(C(X))=H(X)`$.

## (b)
Concatenated encoding is a deterministic function, so
```math
H(C(X^n))\le H(X^n),\qquad
H(X^n)-H(C(X^n))=H(X^n\mid C(X^n))
```
when the entropies are finite. Equality holds exactly when the concatenation map is injective on the block distribution's positive-probability support. Nonunique decodability does not force strict inequality for every $`n`$; at $`n=1`$ equality still holds. For iid full-support input and a non-uniquely-decodable nonempty code, the fixed-block criterion of Exercise 5.21 implies some block length has a collision and hence strict loss. Appending a common source suffix shows that all sufficiently large block lengths then have strict loss as well.

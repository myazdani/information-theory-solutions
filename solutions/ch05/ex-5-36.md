# Exercise 5.36: Which lengths can be binary Huffman lengths?

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 155. Logarithms are base 2 unless explicitly written as ln.

## Solution

## (a)
The vector $`(1,2,2)`$ is possible: assign probabilities $`(1/2,1/4,1/4)`$. The vector $`(2,2,3,3)`$ is impossible for a finite binary Huffman tree because its Kraft sum is $`1/4+1/4+1/8+1/8=3/4<1`$.

## (b)
For a finite alphabet with at least two symbols, a vector of positive integer lengths is realizable by binary Huffman coding if and only if
```math
\sum_i2^{-\ell_i}=1.
```
Necessity follows because every binary Huffman merge creates a node with exactly two children, so the final tree is full. Conversely Kraft equality provides a full prefix tree with the given lengths; assign $`p_i=2^{-\ell_i}`$. These probabilities sum to one and the tree has mean entropy, hence is optimal. To see that the actual Huffman procedure can produce it, choose a deepest sibling pair: both leaves have the smallest dyadic mass. Merge that pair, which replaces two masses $`2^{-d}`$ by their parent mass $`2^{-(d-1)}`$, and continue inductively on the contracted tree, choosing ties consistently. The singleton case permits length zero. An infinite alphabet is outside the finite terminating Huffman procedure characterized here.

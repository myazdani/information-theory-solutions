# Exercise 5.45: Random subset questions

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 157. Logarithms are base 2 unless explicitly written as ln.

## Solution

Each question is sampled independently and uniformly from all subsets, so membership indicators of different objects are independent fair bits for that question.

## (a)
For one question, object 2 agrees with object 1 with probability $`1/2`$. Independence across questions gives agreement through $`k`$ questions with probability $`2^{-k}`$.

## (b)
Let $`W_k`$ be the number of wrong objects still consistent with all answers. By linearity of expectation,
```math
\mathbb EW_k=(m-1)2^{-k}.
```
No independence among the agreement indicators is needed for this expectation.

## (c)
For $`m=2^n`$ and integer question count $`k=n+\lceil\sqrt n\rceil`$,
```math
\mathbb EW_k=(2^n-1)2^{-n-\lceil\sqrt n\rceil}
=(1-2^{-n})2^{-\lceil\sqrt n\rceil}\longrightarrow0.
```
When $`\sqrt n`$ is an integer this is exactly the question's $`n+\sqrt n`$ count; the harmless rounding has the same limit.

## (d)
A wrong candidate remains exactly when $`W_k\ge1`$. Markov's inequality therefore gives
```math
\Pr(\text{one or more wrong candidates remain})\le\mathbb EW_k
\le2^{-\lceil\sqrt n\rceil}\longrightarrow0.
```
The correct object is always consistent, so no wrong candidate remaining means that it is uniquely identified. Random questions thus need only a sublinear surplus over the optimal $`n`$ questions to identify the object with probability tending to one.

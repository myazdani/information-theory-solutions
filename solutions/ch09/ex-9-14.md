# Exercise 9.14 — A noise distribution with a noiseless atom

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 294–295.

## Solution

### (a)
For every $`P>0`$, capacity is infinite. The positive-probability noiseless component can carry arbitrarily many distinguishable real amplitudes, even though it appears only one tenth of the time. If $`P=0`$, capacity is zero.

### (b)
Fix any finite $`M`$ and take a uniform constellation of $`M`$ distinct points in $`[-\sqrt P,\sqrt P]`$. Define a processed output that returns a constellation label if the exact received value is one of those points and otherwise declares an erasure. The continuous Gaussian component lands exactly on one of the finitely many points with probability zero. Thus the processed channel is an $`M`$-ary erasure channel with nonerasure probability $`1/10`$, having capacity $`(1/10)\log_2 M`$. An erasure-correcting code transmits any smaller rate reliably, and every symbol obeys the peak-power bound. Letting $`M\to\infty`$ proves unbounded capacity.

This relies on the model's unlimited output precision. Replacing the atom by small positive-variance noise or imposing finite quantization would change the conclusion.

# Exercise 9.5 — Receiver knowledge of an independent fading state

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 291.

## Solution

Since $`X`$ and $`V`$ are independent, $`I(X;V)=0`$. Apply the chain rule in both orders:
```math
I(X;Y,V)=I(X;V)+I(X;Y\mid V)=I(X;Y\mid V),
```
```math
I(X;Y,V)=I(X;Y)+I(X;V\mid Y)\ge I(X;Y).
```
Thus $`I(X;Y\mid V)\ge I(X;Y)`$ for every admissible input law, and maximizing gives the corresponding capacity comparison. This describes revealing $`V`$ to the receiver while retaining the same independent-input constraint. Equality holds precisely when $`I(X;V\mid Y)=0`$. The particular fading equation is consistent with the required independence but is not otherwise needed for the proof.

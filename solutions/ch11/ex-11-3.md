# Exercise 11.3 — The source distribution governing a coding error exponent

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 400.

## Solution

Assume first that $`Q`$ has full support on $`m`$ symbols, and let entropy and $`R`$ use the same base.

### (a)
If $`R\le H(Q)`$, $`Q`$ itself is feasible and the minimum divergence is zero. If $`H(Q)<R<\log_2m`$, the entropy constraint is active. In natural-log units, the Lagrangian for minimizing divergence with $`H(P)\ge R`$ has stationary solution
```math
P_\alpha(x)=\frac{Q(x)^\alpha}{\sum_yQ(y)^\alpha},\qquad0\lt \alpha\lt 1,
```
where $`\alpha=1/(1+s)`$ for a nonnegative constraint multiplier $`s`$. Choose $`\alpha`$ so $`H(P_\alpha)=R`$. Convexity of divergence and convexity of the feasible entropy superlevel set make the multiplier solution globally optimal and unique. Entropy increases continuously as $`\alpha`$ decreases from 1 to 0; its derivative is governed by the nonnegative variance of $`\ln Q`$ under the tilt. At $`R=\log_2m`$ the solution is uniform. Above it the feasible set is empty, corresponding to a rate large enough to describe every sequence without error. If $`Q`$ has zeros, use its support for any finite-divergence solution.

### (b)
Write $`q=Q(1)`$. The positive-exponent region is $`h_2(q)<R`$. For $`0<R<1`$, let $`q_R\in(0,1/2)`$ solve $`h_2(q_R)=R`$. The region is
```math
q\in[0,q_R)\ \cup\ (1-q_R,1].
```
Inside it, the minimizing exponent is strictly positive and the universal code's error tends to zero exponentially. For $`h_2(q)>R`$, reliable fixed-rate compression is impossible. At equality the exponent is zero and the exponent formula alone gives no vanishing-error guarantee. For a nonuniform nondeterministic Bernoulli source at exactly its entropy rate with exactly $`2^{nR}`$ descriptions, information-density fluctuations prevent vanishing error. At $`R=1`$, storing the whole binary block works for every $`q`$. Sublinear overhead conventions can matter at other rate boundaries and should not be hidden in the exponent notation.

# Exercise 11.28 — A small empirical variance as a type constraint

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 408.

## Solution

Assume a finite numeric alphabet for the standard type-theorem argument; extensions to unbounded alphabets require suitable moment and large-deviation conditions.

### (a)
For empirical type $`P_n`$, the sample mean and second moment are $`\sum_xP_n(x)x`$ and $`\sum_xP_n(x)x^2`$. The exact feasible set is
```math
\mathcal E_\alpha=\left\{P:\ P(x)\ge0,\ \sum_xP(x)=1,
\ \sum_xP(x)x^2-\left(\sum_xP(x)x\right)^2\le\alpha\right\}.
```
This set is generally nonconvex, so one must not infer a unique projection from convexity.

### (b)
The source uses a non-strict constraint in (a) but a strict probability event in (b). For $`\alpha>0`$, the natural-log exponent of the literal strict event is
```math
J(\alpha)=\inf_{P\in\mathcal E_\alpha}D(P\|Q),\qquad
Q^n(\text{sample variance}\lt \alpha)=\exp[-n(J(\alpha)+o(1))].
```
Finite-alphabet type bounds prove the upper bound, and feasible approximating types give the matching lower bound. For $`\alpha>0`$, a boundary law can be approximated from the strictly lower-variance side by slightly favoring a support point closest to its mean, then rounding sufficiently finely. Indeed, mixing mass $`t`$ into such a point at squared distance $`d^2\le\alpha`$ changes boundary variance to $`\alpha+t(d^2-\alpha)-t^2d^2\lt\alpha`$. Thus strict feasible types approach the closed-set infimum, and the displayed exponent is unchanged by the strict inequality.

A useful parametric form uses $`\mathrm{Var}_P(X)=\min_c\mathbb E_P(X-c)^2`$. Therefore
```math
J(\alpha)=\inf_{c\in[\min\mathcal X,\max\mathcal X]}
\sup_{\beta\ge0}\left\{-\beta\alpha-\ln\sum_xQ(x)e^{-\beta(x-c)^2}\right\}.
```
For fixed $`c`$, this is the KL projection under one linear cost constraint, with tilted law $`P_{c,\beta}(x)\propto Q(x)e^{-\beta(x-c)^2}`$. Choose $`\beta`$ to meet the cost budget unless it is inactive; endpoint cases follow by limits. The outer minimization must be global. Where the optimum is interior and $`\beta>0`$, differentiating in $`c`$ gives $`c=\mathbb E_PX`$.

If $`\alpha>0`$ and $`\alpha\ge\mathrm{Var}_Q(X)`$, the exponent is zero. For the literal strict event at $`\alpha\le0`$, probability is zero and the exponent is infinite, since empirical variance cannot be negative. For comparison, only the non-strict variant at $`\alpha=0`$ is the event that all observations equal one symbol; that variant has probability $`\sum_xQ(x)^n`$ and exponent $`-\ln\max_xQ(x)`$.

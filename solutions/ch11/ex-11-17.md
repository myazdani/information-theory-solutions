# Exercise 11.17 — Expected likelihood is maximized at the true law

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 404–405.

## Solution

Use natural logarithms consistently for entropy and divergence.

### (a)
Independence and linearity give
```math
\mathbb E_{\theta_0}\ell_\theta(X^n)
=n\int f_{\theta_0}(x)\ln f_\theta(x)\,dx
=-n[h(f_{\theta_0})+D(f_{\theta_0}\|f_\theta)].
```
This uses the identity obtained by adding and subtracting $`\ln f_{\theta_0}`$ in the integral. If the candidate density vanishes on a set of positive true probability, its expected log likelihood is negative infinity.

### (b)
The entropy term is fixed, and divergence is nonnegative with value zero at the true density. Thus the expected log likelihood is maximized at $`\theta=\theta_0`$. It is uniquely maximized in the parameter only if the family is identifiable: another parameter defining exactly the same density attains the same value. This is a statement about the expected likelihood, not a claim that every finite-sample maximum-likelihood estimate equals the true parameter.

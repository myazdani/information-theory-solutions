# Exercise 4.31: Counting the current run

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 100. Logarithms are base 2 unless explicitly written as ln.

## Solution

Interpret the Bernoulli sequence as iid, with the initial run count zero before the first sample, as in the example.

## (a)
Independence gives $`H(X_1^n)=nh_2(p)`$, so the source rate is $`h_2(p)`$.

## (b)
The sequence $`Y_1^n`$ is determined from $`X_1^n`$ by incrementing a counter on a 1 and resetting it on a 0. Conversely $`X_i=\mathbf1_{\{Y_i>0\}}`$. Therefore the two blocks are bijective and have the same entropy $`nh_2(p)`$, giving the same rate $`h_2(p)`$. Equivalently, the counter state jumps from $`k`$ to $`k+1`$ with probability $`p`$ and to 0 with probability $`1-p`$, so every row has entropy $`h_2(p)`$. This includes the zero-rate endpoint cases.

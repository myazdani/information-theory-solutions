# Exercise 4.19: A random walk on five vertices

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 96–97. Logarithms are base 2 unless explicitly written as ln.

## Solution

The source diagram has edges $`12,15,14,23,25,35,34,45`$. Degrees are $`(3,3,3,3,4)`$ with total degree 16. Assume each available neighbor is chosen uniformly.

## (a)
For any undirected graph, $`\pi_i=d_i/(2|E|)`$ satisfies detailed balance, since $`\pi_iP_{ij}=1/(2|E|)`$ on every directed edge. Thus
```math
\pi=(3/16,3/16,3/16,3/16,1/4).
```
The graph is connected, so this stationary distribution is unique.

## (b)
At a degree-$`d_i`$ vertex the next-step entropy is $`\log_2d_i`$. Therefore
```math
h=\sum_i\pi_i\log_2d_i=\frac34\log_23+\frac12\approx1.6887218755.
```

## (c)
The stationary one-state entropy is $`H(\pi)=7/2-(3/4)\log_23`$. Hence
```math
I(X_n;X_{n+1})=H(\pi)-h=3-\frac32\log_23\approx0.6225562489.
```

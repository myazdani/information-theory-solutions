# Exercise 4.3: A random shuffle cannot reduce entropy

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 89. Logarithms are base 2 unless explicitly written as ln.

## Solution

First, conditioning reduces entropy, so $`H(TX)\ge H(TX\mid T)`$. For any fixed shuffle $`T=t`$, applying the known inverse permutation $`t^{-1}`$ is an invertible relabeling, so $`H(TX\mid T)=H(T^{-1}TX\mid T)`$. The inverse cancels the shuffle, giving $`H(X\mid T)`$. Finally independence of the input arrangement and chosen shuffle gives $`H(X\mid T)=H(X)`$. These justify the four displayed steps in order.

# Exercise 4.1: Doubly stochastic mixing

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 88. Logarithms are base 2 unless explicitly written as ln.

## Solution

## (a)
Every $`b_j=\sum_i a_iP_{ij}`$ is nonnegative and $`\sum_jb_j=\sum_i a_i\sum_jP_{ij}=1`$. Write the supplied permutation decomposition as $`P=\sum_s\lambda_s\Pi_s`$. Concavity and permutation invariance of entropy give
```math
H(aP)=H\left(\sum_s\lambda_sa\Pi_s\right)
\ge\sum_s\lambda_sH(a\Pi_s)=H(a).
```

## (b)
For $`u=(1/n,\ldots,1/n)`$, the column sums imply $`(uP)_j=(1/n)\sum_iP_{ij}=1/n`$. Thus the uniform law is a stationary distribution. This does not assert uniqueness: for example the identity matrix has every probability vector stationary. Irreducibility would ensure uniqueness.

## (c)
If $`uP=u`$, the same coordinate calculation forces $`\sum_iP_{ij}=1`$ for every column. A transition matrix already has nonnegative entries and row sums one, so it is doubly stochastic.

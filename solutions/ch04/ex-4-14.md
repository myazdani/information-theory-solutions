# Exercise 4.14: Entropy rates under deterministic observations

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 93–94. Logarithms are base 2 unless explicitly written as ln.

## Solution

## (a)
The observed block $`Y_1^n`$ is a deterministic function of $`X_1^n`$, so $`H(Y_1^n)\le H(X_1^n)`$. A coordinatewise fixed function preserves stationarity. Divide by $`n`$ and pass to the entropy-rate limits to obtain $`h(Y)\le h(X)`$.

## (b)
The pair-window process is stationary as well, and $`Z_1^n`$ is a function of $`X_1^{n+1}`$. Therefore
```math
\frac1nH(Z_1^n)\le\frac{n+1}{n}\frac1{n+1}H(X_1^{n+1})\longrightarrow h(X).
```
Thus $`h(Z)\le h(X)`$. Either equality or strict inequality is possible: take $`\psi(x,x')=x`$ for equality, or a constant function applied to a positive-rate source for strict inequality. These arguments use finite one-symbol entropy to ensure the ordinary finite entropy-rate limits.

# Exercise 4.4: Statewise uncertainty can fall

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 89. Logarithms are base 2 unless explicitly written as ln.

## Solution

Use three states $`0,1,2`$ with transition probabilities
```math
P=\begin{pmatrix}0&1/2&1/2\\1&0&0\\1&0&0\end{pmatrix},
\qquad\pi=(1/2,1/4,1/4).
```
Direct multiplication gives $`\pi P=\pi`$, so starting in $`\pi`$ makes the process stationary. Given $`X_1=0`$, the next state is a fair choice between 1 and 2, but the following state is certainly 0. Consequently
```math
H(X_2\mid X_1=0)=1,\qquad H(X_3\mid X_1=0)=0.
```
Thus the averaged conditional entropy can have the stated monotonicity while the entropy for a particular conditioned state decreases.

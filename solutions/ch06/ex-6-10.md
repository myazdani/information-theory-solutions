# Exercise 6.10 — Cost of probability misspecification

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 179.

## Solution

## (a)
The true optimum uses $`p=(1/2,1/4,1/4)`$. The mistaken bettor uses $`q=(1/4,1/2,1/4)`$. Directly,
```math
W^*=\tfrac12\log_2 2+\tfrac12\log_2(3/4)
=\tfrac12\log_2 3-\tfrac12\approx0.2924812504,
```
whereas
```math
W=\tfrac12\log_2 1+\tfrac14\log_2(3/2)+\tfrac14\log_2(3/4)
=\tfrac14\log_2(9/8)\approx0.0424812504.
```
The loss is $`\Delta W=1/4`$ bit per race.

## (b)
For any positive odds,
```math
W^*-W=\sum_i p_i[\log_2(p_i o_i)-\log_2(q_i o_i)]
=D(p\|q).
```
The loss is independent of the odds. If $`q_i=0<p_i`$ the loss is infinite and the mistaken strategy eventually goes broke. This argument uses the fully invested betting model, as in the exercise.

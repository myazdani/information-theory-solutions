# Exercise 6.3 — Entropy of colors without replacement

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 177.

## Solution

## (a) and (b)
Each position in a uniformly shuffled deck is red or black with equal probability, so $`H(X_1)=H(X_2)=1`$ bit. The cards need not be independent for this conclusion.

## (c)
Let $`a_k=H(X_k\mid X_1,\ldots,X_{k-1})`$. Exchangeability of the color sequence gives
```math
a_{k+1}=H(X_{k+1}\mid X_1^{k-1},X_k)
\le H(X_{k+1}\mid X_1^{k-1})
=H(X_k\mid X_1^{k-1})=a_k.
```
Thus the conditional entropy decreases (is nonincreasing), from $`a_1=1`$ to $`a_{52}=0`$. It is strictly decreasing here: for every $`k<52`$ there is a positive-probability prefix for which both colors remain and observing the next card changes the distribution of the following one.

## (d)
Every binary color sequence with 26 cards of each color is equally likely. There are $`\binom{52}{26}`$ such sequences, hence
```math
H(X_1,\ldots,X_{52})=\log_2\binom{52}{26}.
```

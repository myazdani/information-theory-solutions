# Exercise 12.7: A minimax linear prediction error

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed p. 422.

## Solution

Assume the prescribed $`(p+1)\times(p+1)`$ moment Toeplitz matrix is positive definite, as is necessary for a nonsingular joint density. Define

```math
T=(R_{|i-j|})_{i,j=1}^p,\qquad r=(R_1,\ldots,R_p)^T,
\qquad a=T^{-1}r,\qquad \sigma^2=R_0-r^TT^{-1}r.
```

The answer is $`\sigma^2`$. To establish the upper bound, use only the most recent $`p`$ variables. Expanding the error of this predictor gives

```math
E\left(X_n-\sum_{j=1}^pa_jX_{n-j}\right)^2
=R_0-2a^Tr+a^TTa=\sigma^2.
```

It is available for every feasible joint density, hence the best predictor cannot have larger error.

For attainment, construct a Gaussian order-$`p`$ Markov extension. Start with a zero-mean Gaussian vector of length $`p`$ with moment matrix $`T`$, and recursively set

```math
X_i=\sum_{j=1}^p a_jX_{i-j}+Z_i,\qquad Z_i\stackrel{\rm iid}{\sim}N(0,\sigma^2),
```

independently of the initial vector. The Yule–Walker identities $`Ta=r`$ imply that the newly appended variable has the prescribed covariances with the preceding $`p`$ variables and variance $`R_0`$. Induction shows that every moving block of length $`p+1`$ has the required Toeplitz matrix. The innovation is independent of the entire past, so no linear predictor using additional past variables reduces its variance below $`\sigma^2`$. This proves both attainment and the minimax value. For $`p=0`$ the answer is $`R_0`$, attained by independent zero-mean Gaussian variables. Singular prescribed matrices admit no full-dimensional density; if singular laws are allowed, use a pseudoinverse and the corresponding deterministic innovation limits.

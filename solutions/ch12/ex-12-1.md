# Exercise 12.1: A gamma maximum-entropy law

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed p. 421.

## Solution

Use natural logarithms, as in the entropy functional in this exercise. For a nondegenerate density with finite constraints, feasibility requires $`\alpha_1>0`$ and $`\alpha_2<\ln\alpha_1`$ by strict Jensen. The optimizer is gamma:

```math
f_*(x)=\frac{\beta^k}{\Gamma(k)}x^{k-1}e^{-\beta x},\qquad x>0,
\quad k>0,\quad\beta>0,
```

where

```math
\beta=k/\alpha_1,\qquad
\psi(k)-\ln k=\alpha_2-\ln\alpha_1.
```

Here $`\psi=\Gamma'/\Gamma`$. The function $`\psi(k)-\ln k`$ increases from $`-\infty`$ to 0: its derivative is $`\sum_{j\ge0}(k+j)^{-2}-1/k>0`$, by comparison with the integral of the decreasing function $`(k+t)^{-2}`$. Thus the stated strict feasibility conditions select a unique shape and rate.

To prove optimality, observe that $`\ln f_*`$ is a linear combination of $`1,x,\ln x`$. Every feasible $`f`$ has the same expectation of this log density. Hence

```math
D(f\Vert f_*)=-h(f)-\int f\ln f_*
=h(f_*)-h(f)\ge0.
```

Equality holds only for $`f=f_*`$ almost everywhere. Its entropy is
$`k-\ln\beta+\ln\Gamma(k)+(1-k)\psi(k)`$. If $`\alpha_2=\ln\alpha_1`$, only a point mass can satisfy the constraints, so there is no feasible Lebesgue density.

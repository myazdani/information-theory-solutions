# Exercise 7.10 — The pentagon channel and its zero-error rate

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 225–226.

## Solution

### (a)
Every row has entropy 1, and uniform input yields uniform output on five symbols. Hence $`C=\log_2 5-1=\log_2(5/2)`$.

### (b)
Two distinct symbols are confusable precisely when their difference is $`\pm2\pmod5`$; a difference $`\pm1`$ gives disjoint output sets. The five length-two codewords
```math
\{(i,2i\bmod5):i=0,1,2,3,4\}
```
have zero error: a difference $`\pm1`$ is distinguished in the first coordinate, and a difference $`\pm2`$ is distinguished in the second. Their rate is $`\frac12\log_2 5>1`$.

For completeness, an upper bound proves the exact value without assuming the cited result. Put $`\beta^2=1/\sqrt5`$, $`\alpha^2=1-1/\sqrt5`$, and define unit vectors
```math
u_j=(\alpha\cos(4\pi j/5),\alpha\sin(4\pi j/5),\beta),
\qquad h=(0,0,1).
```
Using $`\cos(4\pi/5)=-(1+\sqrt5)/4`$, we find $`u_j\cdot u_{j\pm1}=0`$, while $`|h\cdot u_j|^2=1/\sqrt5`$. For a zero-error block code of length $`n`$, tensor products $`u_{x_1}\otimes\cdots\otimes u_{x_n}`$ of different codewords are orthogonal: some coordinate must contain a nonconfusable pair. Each tensor vector has squared overlap $`5^{-n/2}`$ with the unit vector $`h^{\otimes n}`$. Bessel's inequality therefore gives $`M5^{-n/2}\le1`$. Hence every zero-error rate is at most $`\frac12\log_2 5`$, and the repeated length-two construction attains
```math
C_0=\tfrac12\log_2 5.
```

# Exercise 7.34 — Capacities of disjoint channel blocks

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 238–239.

## Solution

For disjoint input/output blocks of capacities $`C_j`$, the union capacity is $`\log_2\sum_j2^{C_j}`$. Indeed, for block probabilities $`q_j`$, the information is at most $`H(q)+\sum_jq_jC_j`$, with equality from optimal conditional inputs; this equals $`\log_2\sum_j2^{C_j}-D(q\|q^*)`$, where $`q_j^*\propto2^{C_j}`$.

### (a)
The drawn four-input channel is a choice of two BSC blocks, not simultaneous transmission through two independent binary inputs. Both blocks have capacity $`1-h_2(p)`$, giving
```math
C=2-h_2(p).
```
### (b)
One block is a BSC and the other an isolated noiseless symbol, so
```math
C=\log_2(2^{1-h_2(p)}+1).
```
### (c)
There is an ambiguity in the supplied page's labels: the diagram titled “BSC and a ternary channel” mixes $`1/2`$ labels and $`p`$ labels on the arrows. These cannot all be literal row probabilities for general $`p`$.

Under the usual block interpretation, the three-input cyclic channel sends each input to either of two outputs with equal probabilities, so its capacity is $`\log_2 3-1`$. The other block is a BSC with crossover $`p`$. This interpretation gives
```math
C=\log_2\left(\frac32+2^{1-h_2(p)}\right).
```
If all the displayed one-half probabilities are instead enforced, row normalization forces the binary block to have crossover $`1/2`$ as well, and the result specializes to $`C=\log_2(5/2)`$. A unique general-$`p`$ transition matrix cannot be recovered from inconsistent labels alone; the formula above states its precise assumption instead of silently repairing the figure.

### (d)
The two input rows both have entropy $`h_2(1/3)`$. Equal input probabilities make the three outputs uniform, so
```math
C=\log_2 3-h_2(1/3)=2/3.
```
The output-entropy upper bound proves optimality.

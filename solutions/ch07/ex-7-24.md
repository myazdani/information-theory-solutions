# Exercise 7.24 — Extremal three-point integer noise

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 234.

## Solution

### (a)
Capacity cannot exceed $`\log_2 4=2`$ bits. Choose noise alphabet $`\{0,4,8\}`$; then $`Y\bmod4=X`$, so uniform input achieves 2 bits.

### (b)
The minimum is 1 bit. It is attained for noise $`\{0,1,2\}`$: the output lies in six positions and $`H(Y\mid X)=\log_2 3`$, so $`C\le\log_2 6-\log_2 3=1`$. Equal masses on inputs 0 and 3 make those six outputs uniform and attain equality.

It remains to prove no other triple gives a smaller capacity. Translate the noise set to $`\{0,u,v\}`$ with $`0<u<v`$. If some $`d\in\{1,2,3\}`$ is absent from its positive differences $`\{u,v,v-u\}`$, inputs 0 and $`d`$ have disjoint output supports and transmit one bit without error. Otherwise those three differences must be exactly $`\{1,2,3\}`$, forcing the noise triple to be $`\{0,1,3\}`$ or $`\{0,2,3\}`$. For either exceptional triple, uniform input yields output multiplicities, up to reflection,
```math
(1,2,2,3,2,1,1)/12.
```
Its mutual information is
```math
H(Y)-\log_2 3=\frac32-\frac14\log_2 3>1.
```
These cases exhaust all distinct integer noise triples, completing the lower bound.

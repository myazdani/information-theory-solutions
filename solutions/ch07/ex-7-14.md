# Exercise 7.14 — A deterministic invertible two-bit transformation

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 227.

## Solution

### (a)
The mapping permutes the four input pairs. Consequently $`H(Y_1,Y_2\mid X_1,X_2)=0`$ and $`H(Y_1,Y_2)=H(X_1,X_2)`$. If the input-pair masses are $`p_{00},p_{01},p_{10},p_{11}`$, then
```math
I(X_1,X_2;Y_1,Y_2)=-\sum_{i,j}p_{ij}\log_2p_{ij}.
```
### (b)
The maximum is $`\log_2 4=2`$ bits per pair, attained by uniform input pairs.

### (c)
Under that distribution the input bits are independent fair bits. The first output bit is $`Y_1=X_1\oplus X_2`$, so it is independent of $`X_1`$ and $`I(X_1;Y_1)=0`$. For contrast, restrict the input to 00 and 10 equiprobably: then $`Y_1=X_1`$ and $`I(X_1;Y_1)=1`$, although the whole-pair information is only 1 bit. This verifies the claimed failure of coordinatewise optimization.

# Exercise 7.4 — Additive noise modulo eleven

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 224.

## Solution

### (a)
For every input, $`H(Y\mid X)=H(Z)=\log_2 3`$. Since the output has eleven values,
```math
I(X;Y)\le\log_2 11-\log_2 3=\log_2(11/3).
```
### (b)
A uniform input on $`\{0,\ldots,10\}`$ makes the output uniform by invariance under cyclic shifts. It attains the bound, so $`C=\log_2(11/3)`$ and $`p^*(x)=1/11`$ is a maximizer. It is unique: output uniformity requires $`p_{y-1}+p_{y-2}+p_{y-3}=3/11`$ cyclically. Subtracting adjacent equations gives $`p_i=p_{i-3}`$; because 3 and 11 are coprime, all coordinates are equal.

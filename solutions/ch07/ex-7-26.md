# Exercise 7.26 — Coarsening a four-key typewriter

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 235.

## Solution

### (a)
Every row has entropy 1, and uniform input gives a uniform four-symbol output. Hence $`C=2-1=1`$ bit.

### (b)(i)
For input 1, outputs 1 and 2 fall into different coarse groups. For input 3, outputs 3 and 0 also fall into different groups. Thus either input gives a fair coarse output and $`I(X;Z)=0`$.

### (b)(ii)
Input 0 always gives group $`A`$, and input 2 always gives group $`B`$. Under the stipulated equal probabilities, $`Z`$ determines $`X`$ and $`I(X;Z)=1`$ bit.

### (c)
The coarse output has two symbols, so capacity is at most 1. Part (b)(ii) attains this bound, hence $`C_{X\to Z}=1`$.

### (d)
No. For the distribution in part (b)(i), $`I(X;Y)=1`$ because the output supports for inputs 1 and 3 are disjoint, whereas $`I(X;Z)=0`$. The proposed Markov chain $`X\to Z\to Y`$ would contradict data processing. Directly, conditional on $`Z=A`$, $`Y=1`$ identifies input 1 and $`Y=0`$ identifies input 3, so $`X`$ and $`Y`$ are not conditionally independent given $`Z`$.

# Exercise 7.33 — Feedback creates dependence without communicating new bits

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 238.

## Solution

Write $`h=h_2(p)`$. The output process starts with a fair bit and then follows a BSC transition, since $`X_{i+1}=Y_i`$.

### (a)
Thus $`H(Y^n)=1+(n-1)h`$. The vector $`X^n=(X_1,Y_1,\ldots,Y_{n-1})`$ determines the first $`n-1`$ outputs, leaving only the last independent noise bit uncertain. Therefore
```math
H(Y^n\mid X^n)=h,\qquad I(X^n;Y^n)=1+(n-2)h,
```
and $`n^{-1}I(X^n;Y^n)\to h_2(p)`$.

### (b)
The ordinary BSC capacity is $`1-h_2(p)`$. The displayed limit is larger whenever $`h_2(p)>1/2`$, for example at $`p=1/2`$ when it equals 1 while capacity is zero. This dependence partly runs backward from received noise to future channel inputs and does not measure communicated message information.

### (c)
Only $`X_1`$ depends on the message. The subsequent outputs form $`W\to Y_1\to Y_2\to\cdots`$, so
```math
I(W;Y^n)=I(W;Y_1)\le1-h_2(p).
```
After division by $`n`$, the communication rate tends to zero. There is consequently no conflict with the fact that feedback does not increase BSC capacity.

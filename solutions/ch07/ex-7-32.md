# Exercise 7.32 — Identifying an object by random subset questions

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 237–238.

## Solution

### (a)
Exactly $`n=\log_2 m`$ deterministic yes/no questions suffice, by querying the binary digits of the object's index. Fewer cannot distinguish $`m`$ possibilities because there would be fewer than $`m`$ answer strings.

### (b)
A uniformly random subset assigns independent fair membership bits to all objects. Objects 1 and 2 agree on one answer with probability $`1/2`$; across $`k`$ independent questions their agreement probability is $`2^{-k}`$.

### (c)
Let $`N_k`$ count false objects with identical answer strings. By linearity of expectation,
```math
\mathbb EN_k=(m-1)2^{-k}.
```
No independence among these indicators is needed for this expectation.

### (d)
Use $`k=n+\lceil\sqrt n\rceil`$ to make the number of questions integral. Then $`\mathbb EN_k=(2^n-1)2^{-n-\lceil\sqrt n\rceil}\le2^{-\lceil\sqrt n\rceil}`$.

### (e)
Markov's inequality gives
```math
\Pr(\text{an ambiguous answer string})=\Pr(N_k\ge1)
\le\mathbb EN_k\le2^{-\lceil\sqrt n\rceil}\longrightarrow0.
```
A decoder that outputs the sole consistent object when it is unique therefore has vanishing error. The excess $`\sqrt n`$ questions have vanishing relative overhead.

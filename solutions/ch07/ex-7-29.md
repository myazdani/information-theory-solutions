# Exercise 7.29 — Multiplication by an independent binary switch

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 236.

## Solution

### (a)
For $`q=\Pr(X=1)`$, $`I(X;Y)=h_2(\alpha q)-q h_2(\alpha)`$. If $`0<\alpha\le1`$, differentiation and strict concavity give
```math
q^*=\frac1{\alpha[1+2^{h_2(\alpha)/\alpha}]},\qquad
C=\log_2(1+2^{-h_2(\alpha)/\alpha}).
```
Indeed $`h_2'(\alpha q^*)=h_2(\alpha)/\alpha`$, and substitution gives the stated value. The stationary point lies in $`[0,1]`$; writing $`t=2^{-h_2(\alpha)/\alpha}=\alpha(1-\alpha)^{(1-\alpha)/\alpha}`$ makes this equivalent to $`t\le\alpha/(1-\alpha)`$, which holds for $`0<\alpha<1`$. At $`\alpha=0`$, capacity is zero and every input is optimal; at $`\alpha=1`$, the optimum is fair input and capacity one.

### (b)
If $`Z`$ is observed, then
```math
I(X;Y,Z)=I(X;Z)+I(X;Y\mid Z)=\alpha H(X).
```
The capacity is $`\alpha`$ bits, attained by fair input. This is the same channel as Exercise 7.23, with the complete calculation repeated here.

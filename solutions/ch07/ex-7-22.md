# Exercise 7.22 — Adding an available channel input

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 234.

## Solution

Embed each old input distribution into the enlarged alphabet by assigning probability zero to the new input symbol. The resulting joint law on the old inputs and outputs is unchanged, so its mutual information is unchanged. In particular an old capacity-achieving input law still attains the old capacity in the enlarged channel. Maximizing over the larger set of input laws can therefore only maintain or increase capacity. No assumption about the new row beyond it being a valid transition distribution is necessary.

# Exercise 7.6 — A cyclic typewriter and a zero-error alphabet

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 224–225.

## Solution

### (a)
A noiseless alphabet of size 26 has capacity $`\log_2 26`$ bits, achieved by uniform input.

### (b)
Each channel row has two equally likely outputs, so $`H(Y\mid X)=1`$. Uniform input makes the output uniform, yielding
```math
C=\log_2 26-1=\log_2 13.
```
### (c)
Use every other letter: for example the 13 input letters with even indices $`0,2,\ldots,24`$. Their output pairs partition the alphabet, allowing zero-error decoding. This transmits $`\log_2 13`$ bits per use. It is optimal among length-one zero-error codes because each input has two possible outputs and the output supports must be disjoint, so at most $`26/2=13`$ input symbols can be included.

# Exercise 7.31 — A Bernoulli source and a binary symmetric channel

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 237.

## Solution

Let $`H=h_2(\alpha)`$ and $`C=1-h_2(p)`$; there is one channel use per source symbol.

If $`H<C`$, choose a rate strictly between them. Lossless source coding followed by channel coding makes the block error tend to zero. If $`H>C`$, Fano and data processing give
```math
nH\le I(V^n;Y^n)+1+nP_e\le nC+1+nP_e,
```
so vanishing block error is impossible.

For clarity, the boundary can also be settled for this particular model. If $`H=C=0`$, the source is deterministic and needs no communication. If $`H=C=1`$, the source is fair and the channel is noiseless up to a deterministic flip; direct transmission works. At every intermediate equality $`0<H=C<1`$, vanishing block error is impossible.

Here is a finite-block argument for that last claim. For any deterministic encoder $`f`$ and decoder regions $`D_v`$, take the auxiliary output law uniform on $`\{0,1\}^n`$. Define
```math
J=\log_2\frac{P(V^n)W(Y^n\mid f(V^n))}{2^{-n}}.
```
On $`J\le-\gamma`$, the probability of correct decoding is at most $`2^{-\gamma}`$, because summing $`P(v)W(y\mid f(v))\le2^{-\gamma}2^{-n}`$ over disjoint decoder regions yields that bound. Hence
```math
P_e\ge\Pr(J\le-\gamma)-2^{-\gamma}.
```
For a BSC with independent noise $`Z_i`$,
```math
J=\sum_{i=1}^n[1+\log_2 P_V(V_i)+\log_2 P_Z(Z_i)].
```
These are iid increments of mean $`C-H=0`$ and strictly positive finite variance in the intermediate case. With $`\gamma=n^{1/4}`$, the central limit theorem makes the probability on the right tend to $`1/2`$. Randomized codes cannot improve the best deterministic code, by averaging their random choices. Thus the strict inequality is the exact nondegenerate condition, with the two boundary exceptions described above.

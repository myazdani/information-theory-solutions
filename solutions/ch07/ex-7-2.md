# Exercise 7.2 — A binary input plus a two-point disturbance

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 224.

## Solution

The possible outputs for input 0 are $`\{0,a\}`$ and for input 1 are $`\{1,1+a\}`$. These sets intersect only for $`a=1`$ or $`a=-1`$ (apart from repeated points within a set at $`a=0`$).

If $`a\notin\{-1,1\}`$, the received value determines the input, so $`I(X;Y)=H(X)`$ and capacity is 1 bit, attained by a fair input. At $`a=0`$ the intended limiting model has deterministic zero noise and the same capacity; the literal statement assigning probability $`1/2`$ twice to the identical event should be read in this sense.

For $`a=1`$, output 1 occurs with probability $`1/2`$ independently of the input and gives no information; outputs 0 and 2 reveal the input. The channel is a binary erasure channel with erasure probability $`1/2`$, so $`I(X;Y)=H(X)/2`$ and capacity is $`1/2`$ bit. For $`a=-1`$ the same argument holds with ambiguous output 0. Therefore
```math
C(a)=\begin{cases}1/2,&a=\pm1,\\1,&\text{otherwise}.\end{cases}
```

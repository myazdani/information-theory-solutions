# Exercise 7.8 — Optimizing a one-sided binary channel

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 225.

## Solution

Let $`q=\Pr(X=1)`$. Then $`\Pr(Y=1)=q/2`$ and $`H(Y\mid X)=q`$, giving
```math
I(q)=h_2(q/2)-q.
```
The objective is strictly concave. Its derivative vanishes when
```math
\frac12\log_2\frac{1-q/2}{q/2}-1=0,
```
so $`q/2=1/5`$. Thus the maximizing distribution is $`p_X=(3/5,2/5)`$, and
```math
C=h_2(1/5)-2/5=\log_2(5/4)\approx0.3219280949\text{ bits}.
```
Both endpoint input distributions convey zero information, so the interior stationary point is the global maximum.

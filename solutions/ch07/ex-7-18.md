# Exercise 7.18 — Three finite channel capacities

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 232.

## Solution

### (a)
All channel rows are identical, so input and output are independent for every input law. The capacity is zero.

### (b)
Each row has entropy 1. Uniform input produces uniform output on three symbols, attaining $`H(Y)=\log_2 3`$. Hence $`C=\log_2 3-1`$.

### (c)
The output identifies which of the two disjoint binary blocks was used. Let that choice be $`J`$, with $`\Pr(J=1)=\lambda`$. Conditional block capacities are $`C_p=1-h_2(p)`$ and $`C_q=1-h_2(q)`$. Therefore
```math
C=\max_{0\le\lambda\le1}[h_2(\lambda)+\lambda C_p+(1-\lambda)C_q]
=\log_2(2^{C_p}+2^{C_q}).
```
To verify the last step, put $`\lambda^*=2^{C_p}/(2^{C_p}+2^{C_q})`$; the objective equals $`\log_2(2^{C_p}+2^{C_q})-D(\operatorname{Bern}(\lambda)\|\operatorname{Bern}(\lambda^*))`$. Within each block use its two inputs equiprobably. This gives probabilities $`\lambda^*/2,\lambda^*/2,(1-\lambda^*)/2,(1-\lambda^*)/2`$.

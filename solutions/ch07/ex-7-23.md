# Exercise 7.23 — Binary multiplication with and without state information

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 234.

## Solution

### (a)
Let $`q=\Pr(X=1)`$. Since $`Y=1`$ exactly when $`X=Z=1`$,
```math
I(X;Y)=h_2(\alpha q)-q h_2(\alpha).
```
For $`0<\alpha\le1`$, strict concavity and differentiation give
```math
q^*=\frac1{\alpha[1+2^{h_2(\alpha)/\alpha}]},\qquad
C=\log_2(1+2^{-h_2(\alpha)/\alpha}).
```
The stationary point is feasible: $`2^{-h_2(\alpha)/\alpha}=\alpha(1-\alpha)^{(1-\alpha)/\alpha}\le\alpha/(1-\alpha)`$ when $`\alpha<1`$, which implies $`\alpha q^*\le\alpha`$. At $`\alpha=1`$ this gives $`q^*=1/2,C=1`$. At $`\alpha=0`$, the output is always zero, so $`C=0`$ and every input distribution is optimal.

### (b)
Independence gives $`I(X;Z)=0`$. Conditional on $`Z=0`$ nothing about $`X`$ is revealed, and conditional on $`Z=1`$ the input is seen perfectly. Thus
```math
I(X;Y,Z)=\alpha H(X),\qquad C_{\rm state}=\alpha,
```
attained by a fair input.

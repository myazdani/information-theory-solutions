# Exercise 7.16 — The channel induced by a repetition code

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 231.

## Solution

Use majority decoding for the two length-three repetition words.

### (a)
The decoded bit is wrong if at least two independent flips occur:
```math
p'=3(0.1)^2(0.9)+(0.1)^3=0.028.
```
### (b)
The induced binary symmetric channel has capacity $`1-h_2(0.028)`$ per three-symbol codeword. Per original transmission this is $`[1-h_2(0.028)]/3\approx0.2719131356`$ bit.

### (c)
The original capacity is $`1-h_2(0.1)`$ bits per transmission, approximately $`0.5310044064`$, which is larger.

### (d)
For any length-$`n`$ encoder and decoder, the variables form $`M\to X^n\to Y^n\to\widehat M`$. By data processing and the memoryless product-channel bound,
```math
I(M;\widehat M)\le I(X^n;Y^n)\le nC.
```
Maximize the left side over the input message distribution and divide by $`n`$. This proves that including the encoder and decoder in a superchannel cannot increase capacity per original use. The bound covers stochastic encoders and decoders with private randomness too.

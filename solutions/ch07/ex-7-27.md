# Exercise 7.27 — An independent erasure after an arbitrary channel

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 235–236.

## Solution

Let $`E`$ indicate erasure. It is independent of $`X`$, has probability $`\alpha`$, and is observable from the final output. Thus for every input law,
```math
I(X;S)=I(X;E)+(1-\alpha)I(X;Y\mid E=0)+\alpha I(X;S\mid E=1)
=(1-\alpha)I(X;Y).
```
Maximizing gives $`C_{\rm cascade}=(1-\alpha)C`$. Any capacity-achieving law of the original channel remains optimal when $`\alpha<1`$; if all symbols are erased, capacity is zero. The nonerased transition probability on the source page uses $`\bar\alpha=1-\alpha`$, as required for row normalization.

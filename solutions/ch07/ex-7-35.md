# Exercise 7.35 — Adding noiseless symbols to a channel

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 239.

## Solution

### (a)
The new row and column form an isolated one-symbol block of capacity zero. Let $`q`$ be the probability of using the original block. The best information at this choice is $`h_2(q)+qC`$. It is maximized at $`q=2^C/(2^C+1)`$, giving
```math
\widetilde C=\log_2(2^C+1).
```
### (b)
The identity block is a noiseless $`k`$-symbol channel with capacity $`\log_2 k`$. Optimizing $`h_2(q)+qC+(1-q)\log_2 k`$ gives
```math
\widehat C=\log_2(2^C+k),\qquad q^*=\frac{2^C}{2^C+k}.
```
Within the original block use a capacity-achieving input distribution; within the identity block use its symbols uniformly. These choices attain the upper bounds because the output identifies the block.

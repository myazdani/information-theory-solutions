# Exercise 7.1 — Capacity after output processing

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 223.

## Solution

### (a)
For every input distribution, $`X\to Y\to\widetilde Y=g(Y)`$ is a Markov chain. Data processing gives $`I(X;\widetilde Y)\le I(X;Y)\le C`$. Maximizing the left side cannot yield a capacity above $`C`$.

### (b)
For a finite-alphabet channel, equality of the capacities holds exactly when there exists an input distribution $`p^*`$ such that
```math
I_{p^*}(X;Y)=C,\qquad I_{p^*}(X;Y\mid\widetilde Y)=0.
```
Indeed the chain rule gives $`I(X;Y)=I(X;\widetilde Y)+I(X;Y\mid\widetilde Y)`$, proving sufficiency. Conversely, an input attaining the processed-channel capacity $`C`$ must make both inequalities in part (a) equalities, giving the conditions. The second condition means that on this input's support, the posterior distribution of $`X`$ given $`Y=y`$ is identical for outputs merged by $`g`$. Injectivity of $`g`$ is sufficient, but unnecessary.

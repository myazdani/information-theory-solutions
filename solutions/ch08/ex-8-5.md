# Exercise 8.5 — Entropy under a linear coordinate change

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 257.

## Solution

Let $`X`$ have a density on $`\mathbb R^n`$ and let $`A`$ be an invertible $`n\times n`$ matrix. The change-of-variables formula gives
```math
f_{AX}(y)=f_X(A^{-1}y)/|\det A|.
```
Hence, whenever the entropy is defined,
```math
h(AX)=-\mathbb E\log f_{AX}(AX)
=-\mathbb E\log f_X(X)+\log|\det A|
=h(X)+\log|\det A|.
```
The same logarithm base must be used throughout. Invertibility is essential: if $`A`$ is singular, $`AX`$ is supported on a lower-dimensional subspace and has no full-dimensional Lebesgue density. One can describe its full-dimensional entropy informally as negative infinity, but the usual density-based definition is not applicable.

# Exercise 8.4 — Bits for a quantized decay time

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 257.

## Solution

Interpret three-digit accuracy as a quantization step of $`\Delta=10^{-3}`$ year. An exponential lifetime with median 80 has rate $`\lambda=(\ln2)/80`$, since $`e^{-80\lambda}=1/2`$. The small-bin entropy approximation is
```math
H(Q_\Delta(X))\simeq h_2(X)+\log_2(1/\Delta)
=\log_2\frac{e}{\lambda\Delta}\approx18.2592\text{ bits}.
```
The exact bin probabilities are geometric: $`p_k=(1-e^{-\lambda\Delta})e^{-k\lambda\Delta}`$, $`k\ge0`$. Consequently their entropy is
```math
H=-\log_2(1-e^{-u})+\frac{u}{\ln2}\frac{e^{-u}}{1-e^{-u}},\qquad u=\lambda\Delta,
```
which confirms the approximation. A binary prefix code can have expected length below $`H+1`$ bits; efficient block coding approaches $`H`$. Three significant digits would specify a different, nonuniform quantizer, so its entropy cannot be inferred from the fixed-resolution formula without that convention.

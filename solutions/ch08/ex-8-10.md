# Exercise 8.10 — A fourth-power typical shell

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 258.

## Solution

Normalize the density: $`c=2/\Gamma(1/4)`$. A gamma-integral substitution, or integration by parts, gives $`\mathbb E X^4=1/4`$. Thus the natural-log entropy is $`h_{\rm nat}=-\ln c+1/4`$. For an iid block,
```math
-\frac1n\ln f(x^n)=-\ln c+\frac1n\sum_{i=1}^n x_i^4.
```
With consistently natural-log typicality, the set is exactly
```math
\left\{x^n:\ n(1/4-\epsilon)<\sum_i x_i^4<n(1/4+\epsilon)\right\},
```
with nonnegative lower radius understood. It is a thin shell between concentric $`\ell_4`$ balls, with radius about $`(n/4)^{1/4}`$, rather than a Euclidean spherical shell. With entropy in bits, replace the tolerance $`\epsilon`$ above by $`\epsilon\ln2`$.

The printed exercise defines $`h`$ using $`\ln`$ but writes a typicality threshold with base 2. Taken literally, that threshold instead gives
```math
\frac1n\sum_i x_i^4\in\bigl((h-\epsilon)\ln2+\ln c,
(h+\epsilon)\ln2+\ln c\bigr).
```
It still specifies an $`\ell_4`$ shell, but is not the usual high-probability typical set. The first description corrects this base mismatch explicitly.

# Exercise 15.20: Exponentiation and a change of input alphabet

Source: Cover and Thomas, 2nd ed. (2006), p. 604, Exercise 15.20. The displayed operation is exponentiation, $`Y=X_1^{X_2}`$, not multiplication.

## Solution

### (a) Original alphabets

Write $`X_1=2^{2^A}`$ and $`X_2=2^B`$, where $`A,B\in\{0,1\}`$. The invertible output relabeling $`\log_2\log_2Y`$ equals $`A+B`$. Thus this is the binary adder MAC, with capacity region

```math
R_1,R_2\ge0,\qquad R_1\le1,\quad R_2\le1,\quad R_1+R_2\le3/2.
```

For completeness, independent fair bits give conditional entropies $`1,1`$ and output entropy $`3/2`$, attaining the pentagon. To bound the output entropy for arbitrary independent Bernoulli parameters $`p,q`$, set $`a=(1-p)(1-q),b=p+q-2pq,c=pq`$. The derivative difference of $`H(a,b,c)`$ is $`(p-q)\log_2(ac/b^2)`$. Since $`b^2\ge4ac`$, averaging $`p,q`$ at fixed sum increases entropy. At $`p=q=t`$, entropy is $`2h_2(t)-2t(1-t)`$, strictly concave and symmetric, with maximum $`3/2`$ at $`t=1/2`$. Boundary laws follow by continuity.

### (b) Replacing the first alphabet by {1,2}

Let $`p=P(X_1=2)`$ and $`q=P(X_2=2)`$. The three distinct output values are $`1,2,4`$, with probabilities $`1-p,p(1-q),pq`$. The output always reveals $`X_1`$; it reveals $`X_2`$ exactly when $`X_1=2`$. Hence

```math
I(X_1;Y\mid X_2)=h_2(p),\qquad
I(X_2;Y\mid X_1)=p h_2(q),\qquad
I(X_1,X_2;Y)=h_2(p)+p h_2(q).
```

The sum constraint is redundant. Choosing $`q=1/2`$ dominates every other $`q`$, so the new region is

```math
\mathcal C'=\bigcup_{0\le p\le1}
\{0\le R_1\le h_2(p),\ 0\le R_2\le p\}.
```

It is already convex: concavity of $`h_2`$ puts every convex combination of points below the rectangle at the averaged $`p`$. Equivalently,

```math
0\le R_2\le1,\qquad
0\le R_1\le
\begin{cases}
1,&0\le R_2\le1/2,\\
h_2(R_2),&1/2\le R_2\le1.
\end{cases}
```

The regions are **not ordered by inclusion**. The old point $`(1/2,1)`$ is impossible in the new channel because $`R_2=1`$ forces $`p=1`$ and hence $`R_1=0`$. On the other hand, $`(h_2(2/3),2/3)`$ belongs to the new region and has sum $`\log_2 3>3/2`$, so it is outside the old one. In particular the maximum throughput increases from $`3/2`$ to $`\log_2 3`$, although some former rate pairs are lost. Changing an alphabet from $`\{2,4\}`$ to $`\{1,2\}`$ is not deleting input symbols from a fixed channel, so there is no monotonicity principle requiring a decrease.

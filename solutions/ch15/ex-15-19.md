# Exercise 15.19: A source supported on two coordinate axes

Source: Cover and Thomas, 2nd ed. (2006), p. 603, Exercise 15.19. Assume $`m\ge2`$, $`\alpha,\beta,\gamma\ge0`$, and $`\alpha+\beta+\gamma=1`$.

## Solution

There are three disjoint events: both variables are zero (mass $`\alpha`$), only $`U_2`$ is nonzero (mass $`\beta`$), or only $`U_1`$ is nonzero (mass $`\gamma`$). Within either nonzero event the nonzero symbol is uniform over $`m-1`$ values. Thus, with $`L=\log_2(m-1)`$,

```math
H(U_1,U_2)=H(\alpha,\beta,\gamma)+(\beta+\gamma)L,
```

```math
H(U_1)=h_2(\gamma)+\gamma L,\qquad
H(U_2)=h_2(\beta)+\beta L.
```

Subtracting marginals from the joint entropy gives the exact Slepian–Wolf region

```math
R_1\ge H(\alpha,\beta,\gamma)-h_2(\beta)+\gamma L,
```

```math
R_2\ge H(\alpha,\beta,\gamma)-h_2(\gamma)+\beta L,
```

```math
R_1+R_2\ge H(\alpha,\beta,\gamma)+(\beta+\gamma)L.
```

For an equivalent conditional interpretation, the first lower bound is

```math
(\alpha+\gamma)h_2\left(\frac{\gamma}{\alpha+\gamma}\right)+\gamma L.
```

When $`U_2\ne0`$, $`U_1`$ is already known to be zero; otherwise the receiver must distinguish the zero event from a uniform nonzero symbol. The second bound has the analogous expression with $`\beta`$ in place of $`\gamma`$. Interpret a term with zero prefactor by continuity. The entropy-difference formulas avoid all zero-denominator issues and apply on every face of the parameter simplex.

# Exercise 15.9: A binary noisy source pair

Source: Cover and Thomas, 2nd ed. (2006), p. 599, Exercise 15.9. Write $`h_2(t)=-t\log_2t-(1-t)\log_2(1-t)`$, with $`0\log_2 0=0`$.

## Solution

Let $`q=p(1-r)+(1-p)r`$. Then $`Y\sim\operatorname{Bernoulli}(q)`$. Given $`X`$, the variable $`Y`$ is a relabeling of the independent noise bit, and the map $`(X,Z)\mapsto(X,Y)`$ is bijective. Consequently

```math
H(Y\mid X)=h_2(r),\qquad H(X,Y)=h_2(p)+h_2(r),
```

and

```math
H(X\mid Y)=h_2(p)+h_2(r)-h_2(q).
```

The closed region allowing joint recovery with vanishing block error is therefore

```math
R_1\ge h_2(p)+h_2(r)-h_2(q),\qquad
R_2\ge h_2(r),\qquad
R_1+R_2\ge h_2(p)+h_2(r).
```

The Slepian–Wolf theorem proves sufficiency as well as necessity; boundaries are understood by closure. The formulas remain valid at $`p,r\in\{0,1\}`$. For example, fair noise makes the sources independent, producing $`R_1\ge h_2(p),R_2\ge1`$; zero noise gives $`R_1,R_2\ge0,R_1+R_2\ge h_2(p)`$.

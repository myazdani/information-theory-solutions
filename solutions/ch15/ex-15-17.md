# Exercise 15.17: A symmetric ternary source pair

Source: Cover and Thomas, 2nd ed. (2006), p. 603, Exercise 15.17. The printed array is a joint probability table, with diagonal entries $`\alpha`$ and off-diagonal entries $`\beta=1/6-\alpha/2`$.

## Solution

### (a) Region for all admissible parameters

Nonnegativity requires $`0\le\alpha\le1/3`$. Every row and column sums to $`1/3`$, so $`H(X)=H(Y)=\log_2 3`$. Let $`t=3\alpha`$. The conditional distribution in each row or column is a permutation of

```math
\left(t,\frac{1-t}{2},\frac{1-t}{2}\right).
```

Its entropy is $`g(t)=h_2(t)+(1-t)`$. Therefore

```math
R_X\ge g(t),\qquad R_Y\ge g(t),\qquad
R_X+R_Y\ge\log_2 3+g(t)
```

is the closed Slepian–Wolf region. Entropy is evaluated continuously at zero probabilities.

### (b) Agreement probability

There are three diagonal entries, so $`P\{X=Y\}=3\alpha=t`$.

### (c) Diagonal-only case

If $`\alpha=1/3`$, then $`\beta=0`$ and $`X=Y`$ is uniform ternary. Here $`g(1)=0`$, giving

```math
R_X,R_Y\ge0,\qquad R_X+R_Y\ge\log_2 3.
```

### (d) Uniform joint table

If $`\alpha=1/9`$, then $`\beta=1/9`$ and the sources are independent uniform ternary variables. Thus $`g(1/3)=\log_2 3`$, and the region is

```math
R_X\ge\log_2 3,\qquad R_Y\ge\log_2 3.
```

The sum inequality is then redundant. These special cases also check that the original table has been treated as a joint law rather than as a channel matrix.

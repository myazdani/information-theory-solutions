# Exercise 15.7: Convexity by concatenation

Source: Cover and Thomas, 2nd ed. (2006), p. 598, Exercise 15.7. The capacity region is the closure of achievable nonnegative rate pairs.

## Solution

Fix $`0<\lambda<1`$ and two achievable rate pairs $`R^{(1)},R^{(2)}`$. In a block of length $`n`$, use a code for the first pair for $`n_1=\lfloor\lambda n\rfloor`$ uses and a code for the second pair for $`n_2=n-n_1`$ uses. Each receiver's message is a pair of independent submessages; the encoder and decoders know the deterministic switching time.

Choose constituent codes with rates tending to their respective target rates and block error probabilities $`e_1(n_1),e_2(n_2)\to0`$. Such codes may be taken at all sufficiently large lengths using the standard achievable-rate definition; equivalently one may use rates arbitrarily below the two targets and then take closure. Receiver $`j`$ obtains

```math
\frac{\log_2 M_{j,1}+\log_2 M_{j,2}}n
\longrightarrow\lambda R_j^{(1)}+(1-\lambda)R_j^{(2)}.
```

The probability that any requested submessage is incorrect is at most $`e_1(n_1)+e_2(n_2)`$, which tends to zero. Hence the weighted rate pair is achievable in the closed capacity region. The cases $`\lambda=0,1`$ use a single constituent code. No random switch visible to a receiver is needed, and the argument works for any fixed finite number of receivers.

# Exercise 15.22: Separate compression of a sum and difference

Source: Cover and Thomas, 2nd ed. (2006), pp. 604–605, Exercise 15.22. Sums and differences are ordinary integer operations.

## Solution

### (a) Slepian–Wolf region

Write

```math
a=(1-p_1)(1-p_2),\quad b=p_1(1-p_2),\quad
c=(1-p_1)p_2,\quad d=p_1p_2.
```

The four source outcomes give $`(X,Y)=(0,0),(1,1),(1,-1),(2,0)`$ with probabilities $`a,b,c,d`$, respectively. The transform is invertible: $`Z_1=(X+Y)/2`$ and $`Z_2=(X-Y)/2`$. Therefore

```math
J:=H(X,Y)=h_2(p_1)+h_2(p_2),\qquad
H(X)=H(a,b+c,d),\qquad H(Y)=H(c,a+d,b).
```

The closed region is

```math
R_X\ge J-H(Y),\qquad R_Y\ge J-H(X),\qquad R_X+R_Y\ge J.
```

Equivalently, its individual lower bounds are

```math
H(X\mid Y)=(a+d)h_2\left(\frac{d}{a+d}\right),\qquad
H(Y\mid X)=(b+c)h_2\left(\frac{b}{b+c}\right).
```

Only $`Y=0`$ leaves uncertainty about the sum, and only $`X=1`$ leaves uncertainty about the difference. Terms with zero prefactors are zero by continuity.

### (b) Comparison to separately compressing the original sources

Independence makes the original region the rectangle

```math
R_{Z_1}\ge h_2(p_1),\qquad R_{Z_2}\ge h_2(p_2).
```

The transformed region contains this rectangle under the coordinate identification $`(R_X,R_Y)=(R_{Z_1},R_{Z_2})`$. To see this without complicated entropy algebra, knowing $`Y`$ and either original bit determines $`X`$, and knowing $`X`$ and either original bit determines $`Y`$. In particular,

```math
H(X\mid Y)=H(Z_1\mid Y)\le H(Z_1),\qquad
H(Y\mid X)=H(Z_2\mid X)\le H(Z_2).
```

The sum-rate minimum remains exactly $`J`$ because the transform is invertible. Thus redistributing which functions each sender sees can enlarge the allowable allocation of rates without lowering the minimum total rate. For independent fair bits the transformed region has $`R_X,R_Y\ge1/2`$ and sum at least two, whereas the original region requires each rate at least one. For completely deterministic bits both regions reduce to the full nonnegative quadrant, so “larger” need not mean strictly larger in every parameter case.

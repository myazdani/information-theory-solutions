# Exercise 15.28: Optimal FDMA bandwidth allocation

Source: Cover and Thomas, 2nd ed. (2006), p. 606, Exercise 15.28. Assume total bandwidth $`W>0`$, noise spectral-density parameter $`N>0`$, and powers $`P_1,P_2\ge0`$.

## Solution

For an interior allocation write $`\lambda=W_1/W`$. Concavity of $`\log_2`$ gives

```math
\frac{R_1+R_2}{W}
=\lambda\log_2\left(1+\frac{P_1}{NW\lambda}\right)
+(1-\lambda)\log_2\left(1+\frac{P_2}{NW(1-\lambda)}\right)
\le\log_2\left(1+\frac{P_1+P_2}{NW}\right).
```

For positive powers, strict concavity makes equality equivalent to

```math
\frac{P_1}{\lambda}=\frac{P_2}{1-\lambda},
```

or

```math
W_1^*=\frac{P_1}{P_1+P_2}W,\qquad
W_2^*=\frac{P_2}{P_1+P_2}W.
```

Thus both bands have the same signal power per unit bandwidth. The maximum throughput is

```math
W\log_2\left(1+\frac{P_1+P_2}{NW}\right).
```

At zero bandwidth use the continuous extension $`w\log_2(1+P/(Nw))\to0`$. If exactly one power is zero, allocating all the bandwidth to the positive-power user is optimal; this is the limiting proportional rule. If both powers vanish, every allocation gives zero throughput and is optimal.

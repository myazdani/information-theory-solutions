# Exercise 15.33: A modulo-four multiple-access channel

Source: Cover and Thomas, 2nd ed. (2006), p. 608, Exercise 15.33. Rates are in bits per use.

## Solution

### (a) Capacity region

For independent inputs the deterministic operation is invertible in either input when the other is given, even though the second alphabet is smaller. Consequently

```math
I(X_1;Y\mid X_2)=H(X_1)\le2,\qquad
I(X_2;Y\mid X_1)=H(X_2)\le1,
```

and $`I(X_1,X_2;Y)=H(Y)\le2`$. These imply the universal outer bounds

```math
R_1,R_2\ge0,\qquad R_2\le1,\qquad R_1+R_2\le2.
```

Choose $`X_1`$ uniform on the four residues and $`X_2`$ an independent fair binary input. A shift of the uniform first input remains uniform, so $`Y`$ is uniform on four residues. The mutual informations are exactly $`2,1,2`$. The MAC coding theorem achieves the whole displayed region, with vertices $`(0,0),(2,0),(1,1),(0,1)`$; the separate bound $`R_1\le2`$ is redundant.

### (b) Maximum throughput

The maximum sum is two bits per use, achieved everywhere on the segment from $`(2,0)`$ to $`(1,1)`$. The four-valued output supplies the matching upper bound, regardless of the input law or time-sharing.

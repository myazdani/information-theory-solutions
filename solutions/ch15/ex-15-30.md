# Exercise 15.30: Two Gaussian base-station observations

Source: Cover and Thomas, 2nd ed. (2006), p. 607, Exercise 15.30. Interpret the evident noise-index typo as $`Z_i\sim N(0,N_i)`$. Assume $`N_i>0`$, fixed real gains $`\alpha_i`$, power $`P\ge0`$, and independent noises. Set $`g_i=\alpha_i^2/N_i`$.

## Solution

### (a) A common decoder

The capacity is

```math
C_{\rm joint}=\frac12\log_2(1+P(g_1+g_2)).
```

To see the information-preserving reduction, whiten the two observations, giving signal direction $`v=(\alpha_1/\sqrt{N_1},\alpha_2/\sqrt{N_2})`$ in independent unit Gaussian noise. An orthogonal rotation puts all signal in the coordinate along $`v`$; the perpendicular coordinate is independent pure noise. The useful coordinate is $`\sqrt{g_1+g_2}X+Z`$, $`Z\sim N(0,1)`$. Its Gaussian capacity is the displayed expression, achieved by a zero-mean Gaussian input of variance $`P`$. If both gains vanish there is no useful coordinate and the formula gives zero.

### (b) Independent receivers: broadcast capacity

Relabel receivers if necessary so that $`g_1\ge g_2`$. The region is the union over $`0\le\theta\le1`$ of

```math
R_1\le\frac12\log_2(1+\theta P g_1),\qquad
R_2\le\frac12\log_2\frac{1+Pg_2}{1+\theta Pg_2},\qquad R_1,R_2\ge0.
```

If $`g_2>g_1`$, exchange the receiver labels in this formula. Achievability uses independent Gaussian layers: a strong-user layer of power $`\theta P`$ and a weak-user layer of power $`(1-\theta)P`$. Receiver 2 decodes its layer while treating the other as Gaussian noise. Receiver 1 can also decode that layer, subtract it, and decode its own. The strong receiver has no smaller signal-to-noise ratio for decoding the weak layer.

Here is a converse establishing the Gaussian optimization. First suppose both gains are positive and normalize the outputs to $`X+\widetilde Z_i`$, with variances $`s_i=1/g_i`$ and $`s_1\le s_2`$. Although the actual noises are independent, the broadcast capacity depends only on the two conditional marginals: each decoder's error does, and joint error vanishes exactly when both individual errors vanish. We may therefore couple the normalized outputs physically as

```math
Y_1=X+Z_1,\qquad Y_2=Y_1+Z',
```

where $`Z'`$ is independent Gaussian noise of variance $`s_2-s_1`$. Apply the degraded broadcast converse with auxiliary $`U`$. Since conditioning on $`X`$ leaves Gaussian noise and $`\mathbb E X^2\le P`$,

```math
\tfrac12\log_2(2\pi e s_1)\le h(Y_1\mid U)
\le\tfrac12\log_2(2\pi e(s_1+P)).
```

For $`P>0`$ define $`\theta\in[0,1]`$ by $`h(Y_1\mid U)=\tfrac12\log_2(2\pi e(s_1+\theta P))`$. The conditional entropy-power inequality implies

```math
h(Y_2\mid U)\ge\tfrac12\log_2(2\pi e(s_2+\theta P)).
```

One may obtain this conditional version by applying the ordinary EPI for each $`u`$ and Jensen's inequality to the convex function $`t\mapsto\log(2^{2t}+2\pi e(s_2-s_1))`$. Then

```math
R_1\le h(Y_1\mid U)-h(Z_1)
=\tfrac12\log_2(1+\theta P/s_1),
```

```math
R_2\le h(Y_2)-h(Y_2\mid U)
\le\tfrac12\log_2\frac{s_2+P}{s_2+\theta P},
```

which are the claimed bounds. The same argument holds when $`s_1=s_2`$, with zero added noise. If $`P=0`$, both rates are zero. If $`g_2=0`$, the weak receiver's rate is zero and the strong receiver has its ordinary Gaussian capacity; if both gains vanish only the origin remains. These cases agree with the displayed gain-based formula.

# Exercise 15.16: An exact-real channel with no noise

Source: Cover and Thomas, 2nd ed. (2006), p. 602, Exercise 15.16. This ideal channel has exact real-valued inputs and observations; no quantization or noise is implicit. Assume finite nonnegative power budgets.

## Solution

### (a) Capacity region

For $`P_1>0,P_2>0`$, every finite rate pair in

```math
\{(R_1,R_2):R_1\ge0,\ 0\le R_2\le1\}
```

is achievable. Thus user 1 has unbounded capacity while user 2 has one bit per use. The individual user-2 upper bound follows because its entire effect on an $`n`$-block output is through the binary sign sequence: even with user 1's message supplied to the receiver,

```math
I(W_2;Y^n\mid W_1)\le H(\mathrm{sgn}(X_2^n))\le n.
```

Fano gives $`R_2\le1`$. There is no finite upper bound on $`R_1`$.

The zero-budget cases are important:

- If $`P_1=0,P_2>0`$, the region is $`R_1=0,0\le R_2\le1`$.
- If $`P_1>0,P_2=0`$, the region is $`R_1\ge0,R_2=0`$, with every finite $`R_1`$ allowed.
- If both budgets are zero, only $`(0,0)`$ is possible.

A zero average squared input forces that input to equal zero almost surely. In particular $`P_2=0`$ forces sign $`-1`$ under the convention in the question; it does not leave a free binary sign.

### (b) A zero-error construction

When $`P_1>0`$, choose $`0<a<\min\{1,\sqrt{P_1}\}`$ and any finite $`M`$ distinct points in $`[-a,a]`$. Use them as user 1's alphabet. When $`P_2>0`$, user 2 uses $`\pm b`$ with $`0<b\le\sqrt{P_2}`$. For every channel use,

```math
Y\in[1-a,1+a]\quad\hbox{or}\quad Y\in[-1-a,-1+a].
```

The intervals are disjoint. The sign of $`Y`$ identifies user 2's bit, and subtracting that sign recovers user 1's exact alphabet point. Each codeword satisfies its power constraint coordinatewise. This sends $`\log_2M`$ bits for user 1 and one bit for user 2, with zero error. Arbitrarily large finite $`M`$ and block message subsets give every finite rate in the stated region. With a zero budget omit the corresponding alphabet and subtract its known fixed contribution.

# Exercise 15.2: Binary group-operation channels

Source: Cover and Thomas, 2nd ed. (2006), p. 596, Exercise 15.2. Rates are in bits per use.

## Solution

### (a) Addition modulo two

The region is

```math
R_1\ge0,\qquad R_2\ge0,\qquad R_1+R_2\le1.
```

The sum cannot exceed one because the output is binary: Fano's inequality bounds the sum by $`H(Y)\le1`$. With independent fair inputs, the channel is deterministic, each input is recoverable when the other is given, and

```math
I(X_1;Y\mid X_2)=I(X_2;Y\mid X_1)=I(X_1,X_2;Y)=1.
```

The MAC coding theorem therefore achieves the triangle. Alternatively, alternate single-user noiseless transmission over fractions of the block; allowing idle symbols fills its interior.

### (b) Multiplication of signs

Use the bijections $`X_j=(-1)^{B_j}`$ and $`Y=(-1)^C`$. Then $`C=B_1\oplus B_2`$. Relabeling input and output symbols changes neither codes nor error probabilities, so the region is exactly the same triangle. Independent uniform signs attain the same mutual informations.

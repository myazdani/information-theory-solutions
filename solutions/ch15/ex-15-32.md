# Exercise 15.32: A deterministic broadcast outer bound

Source: Cover and Thomas, 2nd ed. (2006), pp. 607–608, Exercise 15.32. The independent messages are sent without feedback through finite-alphabet deterministic outputs $`Y_j=f_j(X)`$.

## Solution

For a reliable length-$`n`$ code, Fano's inequality gives, for each receiver,

```math
n(R_j-\epsilon_n)\le I(W_j;Y_j^n)
\le H(Y_j^n)\le\sum_{i=1}^n H(Y_{ji}),\qquad j=1,2.
```

Enlarge the common vanishing remainder if necessary. A decoder that observes both outputs can run both original decoders; its joint error is at most the sum of their errors. Because the messages are independent, Fano then gives

```math
n(R_1+R_2-\epsilon_n)
\le I(W_1,W_2;Y_1^n,Y_2^n)
\le H(Y_1^n,Y_2^n)
\le\sum_{i=1}^n H(Y_{1i},Y_{2i}).
```

All three bounds must hold for one input law. To obtain it, draw a uniform independent time index $`Q`$ and let $`X=X_Q`$, $`Y_j=f_j(X_Q)`$. The input law is $`p(x)=n^{-1}\sum_i p_{X_i}(x)`$. Removing $`Q`$ from entropy conditioning yields simultaneously

```math
\frac1n\sum_iH(Y_{ji})=H(Y_j\mid Q)\le H(Y_j),
```

```math
\frac1n\sum_iH(Y_{1i},Y_{2i})
=H(Y_1,Y_2\mid Q)\le H(Y_1,Y_2).
```

Thus the requested inequalities hold up to $`\epsilon_n`$ for this averaged input distribution. Select a convergent subsequence in the finite-dimensional input simplex; entropy continuity and reliability give, for its limiting law,

```math
R_1\le H(Y_1),\qquad R_2\le H(Y_2),\qquad
R_1+R_2\le H(Y_1,Y_2).
```

In particular it would be insufficient to optimize the three right-hand sides independently. The converse supplies a single common law, as required for a capacity-region outer bound.

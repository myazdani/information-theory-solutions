# Exercise 15.25: Independent coordinates and cooperative messages

Source: Cover and Thomas, 2nd ed. (2006), p. 606, Exercise 15.25.

## Solution

### (a) Noncooperative capacity

Since the output is the ordered pair of inputs, each user sends its own binary input sequence without error and without interference. The exact region is

```math
0\le R_1\le1,\qquad 0\le R_2\le1.
```

The individual outer bounds follow either by counting each user's binary codewords or from $`I(X_j;Y\mid X_{3-j})=H(X_j)\le1`$. Independent fair inputs attain both bounds simultaneously and yield total mutual information two.

### (b) Cooperative capacity

With both encoders knowing both message indices, the input pair becomes a four-letter noiseless alphabet. Its capacity is two bits, giving

```math
R_1,R_2\ge0,\qquad R_1+R_2\le2.
```

Any pair of messages can be combined into a single index and encoded into the pair sequence; the four-valued output gives the matching sum converse. Both regions have maximum throughput two, so cooperation cannot improve their sum-rate maxima. It strictly enlarges the region, however: for example $`(2,0)`$ becomes achievable by using both coordinates to communicate the first message, whereas it violates the old first-user bound.

# Exercise 15.26: Infinite-bandwidth Gaussian multiple access

Source: Cover and Thomas, 2nd ed. (2006), p. 606, Exercise 15.26. Use the continuous-time convention that two-sided noise power spectral density is $`N_0/2>0`$, so the noise power in bandwidth $`W`$ is $`N_0W`$. Rates are bits per second and each user's total power $`P_j`$ is fixed as bandwidth grows.

## Solution

For finite bandwidth the Gaussian MAC region has, for every nonempty sender subset $`S`$,

```math
\sum_{j\in S}R_j\le W\log_2\left(1+\frac{\sum_{j\in S}P_j}{N_0W}\right).
```

As $`W\to\infty`$, using $`\ln(1+x)/x\to1`$ gives

```math
\sum_{j\in S}R_j\le\frac{\sum_{j\in S}P_j}{N_0}\log_2e.
```

These sum inequalities follow from the individual bounds, so the limiting capacity region is the rectangle (or, for more users, the box)

```math
0\le R_j\le\frac{P_j}{N_0}\log_2e\qquad\text{for every }j.
```

This is precisely each user's single-user infinite-bandwidth capacity. It is an outer bound at every bandwidth because $`\ln(1+x)\le x`$. For achievability, any rate vector strictly below these individual limits satisfies all finitely many subset inequalities at sufficiently large bandwidth, since each nonempty subset has a positive limiting gap. Closure includes the simultaneous corner.

An alternative constructive explanation is to split bandwidth into fixed positive fractions $`\lambda_jW`$. The users then do not interfere, and each has rate $`\lambda_jW\log_2(1+P_j/(N_0\lambda_jW))`$, which tends to its own $`P_j\log_2 e/N_0`$. Zero-power users have zero capacity and need no allocated fraction. Infinite bandwidth eliminates the capacity penalty from interference in this limiting sense; it does not make a finite-bandwidth corner equal to the limit.

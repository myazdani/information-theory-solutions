# Exercise 15.31: Adding a user at a saturated Gaussian MAC

Source: Cover and Thomas, 2nd ed. (2006), p. 607, Exercise 15.31. Write $`C(x)=\tfrac12\log_2(1+x)`$, assume $`N>0`$, and let $`S=mP`$ be the old users' total power.

## Solution

### (a) Largest added rate preserving all old rates

The total-rate converse gives

```math
R_0+C(S/N)\le C((S+P_0)/N),
```

so

```math
R_0\le C((S+P_0)/N)-C(S/N)
=C\left(\frac{P_0}{N+S}\right).
```

This upper bound is achievable. With independent Gaussian coding, decode the new user's message first, treating all old-user signals as noise of total variance $`S+N`$. Subtract the new waveform and decode the original users on their original MAC. All exact capacity values here denote the closure of rates achieved with arbitrarily small backoff.

One can also check feasibility without relying only on that decoding description. For any old-user subset $`T`$ of size $`t`$, its unchanged rates satisfy $`\sum_{i\in T}R_i\le C(tP/N)`$. Since the capacity increment from adding $`P_0`$ decreases with existing signal power,

```math
C(tP/N)+C(P_0/(N+S))
\le C(tP/N)+C(P_0/(N+tP))
=C((tP+P_0)/N).
```

These are exactly the new MAC subset constraints involving user 0; all the old subset constraints remain valid. Thus every feasible old rate vector with the given sum can retain its rates while the new user approaches the stated bound. This statement concerns achievable rates and capacity-achieving coding, not a guarantee for every arbitrary finite legacy codebook.

### (b) Equaling the entire old throughput

The equality $`C(P_0/(N+S))=C(S/N)`$ and strict monotonicity of $`C`$ give

```math
P_0=\frac{S(N+S)}{N}
=mP\left(1+\frac{mP}{N}\right).
```

At this power the total capacity is twice the old sum capacity, since $`1+(S+P_0)/N=(1+S/N)^2`$. If $`S=0`$, the target added rate is zero and the smallest power attaining equality is zero.

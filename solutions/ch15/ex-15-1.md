# Exercise 15.1: Cooperative multiple access

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), p. 596, Exercise 15.1. Logarithms are base two. Rates are nonnegative and regions include their limiting boundary.

## Solution

### (a) Both encoders know both messages

Treat the pair of input symbols as one input alphabet. The capacity region is

```math
\mathcal C_{\rm coop}=\{(R_1,R_2)\ge0:R_1+R_2\le C_{\rm coop}\},\qquad
C_{\rm coop}=\max_{p(x_1,x_2)} I(X_1,X_2;Y).
```

Indeed, combine the two message indices into one index of size $`M_1M_2`$, use a point-to-point code on the product alphabet, and let each encoder transmit its coordinate. Conversely Fano's inequality and memorylessness give

```math
n(R_1+R_2-\epsilon_n)
\le I(W_1,W_2;Y^n)
\le\sum_{i=1}^n I(X_{1i},X_{2i};Y_i)
\le nC_{\rm coop},
```

where $`\epsilon_n\to0`$ for reliable codes. Separate single-user bounds do not apply when both encoders know both messages.

### (b) Binary adder

The deterministic output has three values. Set $`p(0,0)=p(1,1)=1/3`$ and split the remaining $`1/3`$ arbitrarily between $`(0,1)`$ and $`(1,0)`$. Then the output is uniform, so

```math
\mathcal C_{\rm coop}=\{R_1,R_2\ge0:R_1+R_2\le\log_2 3\}.
```

For independent inputs, the noncooperative region is

```math
\mathcal C=\{R_1,R_2\ge0:R_1\le1,\ R_2\le1,\ R_1+R_2\le3/2\}.
```

Here is an explicit proof of the sum bound, rather than merely optimizing at fair inputs. Let $`p=P(X_1=1)`$, $`q=P(X_2=1)`$, and set

```math
a=(1-p)(1-q),\quad b=p(1-q)+(1-p)q,\quad c=pq.
```

Writing $`F(p,q)=H(a,b,c)`$, direct differentiation in the open square gives

```math
\partial_pF-\partial_qF=(p-q)\log_2\frac{ac}{b^2}.
```

Because $`b^2\ge4ac`$, replacing $`(p,q)`$ by their average, at fixed sum, cannot decrease entropy. Boundary points follow by continuity. On the diagonal,

```math
F(t,t)=2h_2(t)-2t(1-t),\qquad
\frac{d^2}{dt^2}F(t,t)=4-\frac{2}{(\ln2)t(1-t)}<0.
```

Symmetry places its maximum at $`t=1/2`$, where it is $`3/2`$. The individual bounds follow from binary input entropy. Independent fair inputs give conditional mutual informations $`1,1`$ and total mutual information $`3/2`$, achieving the whole pentagon by the MAC coding theorem. Convexification does not enlarge it. Cooperation strictly increases the maximum sum from $`3/2`$ to $`\log_2 3`$ and permits either individual rate to exceed one.

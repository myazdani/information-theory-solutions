# Exercise 15.14: Learning a binary channel parameter at negligible rate cost

Source: Cover and Thomas, 2nd ed. (2006), p. 601, Exercise 15.14. Both endpoints know the two candidate crossover probabilities; the transmitter knows which candidate is used.

## Solution

If $`p_1=p_2`$, use a capacity-approaching code for that one channel. Otherwise let $`d=|p_1-p_2|>0`$ and prepend $`m_n=\lceil\sqrt n\rceil`$ known ones to an $`n`$-symbol payload code. The receiver counts the fraction $`\widehat p`$ of zeros in the training output and chooses whichever candidate is closer, breaking ties arbitrarily.

Under channel $`p_j`$, the training-zero indicators are i.i.d. Bernoulli($`p_j`$). A wrong choice requires $`|\widehat p-p_j|\ge d/2`$. Hoeffding's bound gives

```math
P\{\hbox{wrong parameter}\}\le2\exp(-m_n d^2/2)\longrightarrow0.
```

For each $`j`$, fix in advance an $`n`$-symbol code with rate approaching $`C(p_j)=1-h_2(p_j)`$ and error tending to zero. The transmitter uses the appropriate code, and after training the receiver uses its corresponding decoder. Both codebooks and message-set sizes are known beforehand; the channel estimate tells the receiver which message set applies. The total error is at most the training error plus the appropriate payload error.

The attained rate for channel $`j`$ is

```math
\frac{\log_2 M_{j,n}}{n+m_n}
=\frac n{n+m_n}\frac{\log_2 M_{j,n}}n\longrightarrow C(p_j).
```

Thus one obtains the separate capacity of each actual channel rather than being restricted to their minimum. At $`p_j=1/2`$ the corresponding message set may be a singleton; at crossover zero or one the same training and noiseless payload construction work. Any training length tending to infinity and satisfying $`m_n=o(n)`$ suffices.

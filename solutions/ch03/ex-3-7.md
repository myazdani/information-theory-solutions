# Exercise 3.7: A short-block sparse-source code

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 66. Logarithms are base 2 unless explicitly written as ln.

## Solution

Let $`K`$ be the number of ones. It has the binomial distribution with $`n=100`$ and $`p=0.005`$.

## (a)
The number of encoded sequences is
```math
M=\sum_{k=0}^3\binom{100}{k}=166751.
```
An injective fixed-length binary code needs $`\lceil\log_2M\rceil=18`$ bits, since $`2^{17}<M\le2^{18}`$.

## (b)
The unencoded probability is
```math
\Pr(K\ge4)=1-\sum_{k=0}^3\binom{100}{k}(0.005)^k(0.995)^{100-k}
\approx0.001673267523.
```

## (c)
The mean and variance are $`\mathbb EK=0.5`$ and $`\mathrm{Var}K=0.4975`$. As $`K`$ is integer-valued, failure implies $`|K-0.5|\ge3.5`$. Chebyshev yields
```math
\Pr(K\ge4)\le\frac{0.4975}{3.5^2}\approx0.04061224490.
```
It is valid but roughly 24 times the exact tail. Using the weaker threshold 2.5 from $`K>3`$ would give 0.0796; exploiting integer support improves that bound.

# Exercise 2.5: When conditional entropy vanishes

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 44. Logarithms are base 2 unless explicitly written as ln.

## Solution

Write
```math
0=H(Y\mid X)=\sum_{x:p(x)>0}p(x)H(p(\cdot\mid x)).
```
Each term is nonnegative. Every conditional entropy in this sum must therefore be zero, and a discrete distribution has zero entropy exactly when it is concentrated at one point. For each positive-probability $`x`$, let $`g(x)`$ be this unique point. Define $`g`$ arbitrarily on null values. Then $`Y=g(X)`$ almost surely, which is the required meaning of being a function of $`X`$.

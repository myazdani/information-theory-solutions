# Exercise 2.4: Entropy of a deterministic function

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 44. Logarithms are base 2 unless explicitly written as ln.

## Solution

## (a)
The joint-entropy chain rule in the order $`X,g(X)`$ gives the first equality.

## (b)
Given $`X=x`$, the value $`g(X)=g(x)`$ is certain, so $`H(g(X)\mid X)=0`$.

## (c)
Apply the same chain rule in the reverse order.

## (d)
Discrete conditional entropy is a weighted sum of nonnegative entropies, so $`H(X\mid g(X))\ge0`$. Thus $`H(g(X))\le H(X)`$. The argument also holds for countable alphabets in the extended nonnegative reals; it does not require subtracting infinities.

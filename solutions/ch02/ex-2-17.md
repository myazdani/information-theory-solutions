# Exercise 2.17: Extracting unbiased bits

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 47. Logarithms are base 2 unless explicitly written as ln.

## Solution

Let $`Z^K`$ denote the whole finite output word, with its length part of the output representation.

## (a)
The input bits are independent, each with entropy $`h_2(p)`$, so their joint entropy is $`nh_2(p)`$.

## (b)
The pair $`(Z^K,K)`$ is a deterministic function of the input word; deterministic processing cannot increase entropy.

## (c)
Apply the joint-entropy chain rule to the length and the word.

## (d)
Given any attainable length $`k`$, the output is uniform on the $`2^k`$ binary words by the required fairness property. Its conditional entropy is exactly $`k`$. Thus $`H(Z^K\mid K)=\mathbb E K`$.

## (e)
$`H(K)\ge0`$ supplies the last inequality.

## A four-input-bit construction
Within each Hamming-weight class, put words in lexicographic order. For weight 0 or 4 output the empty word. For weight 1 or 3, map the four words in order to 00,01,10,11. The weight-2 class is 0011,0101,0110,1001,1010,1100; map its first four words to 00,01,10,11 and its last two to 0,1.

All words of a fixed weight have the same probability for every $`p`$. Each two-bit output receives one word from each of the weight-1, weight-2, and weight-3 classes. Each one-bit output receives one weight-2 word. Hence the required equal-probability property holds for each length, even though $`p`$ is unknown. The expected output length is
```math
8p(1-p)^3+10p^2(1-p)^2+8p^3(1-p).
```
At $`p=1/2`$ this is $`13/8`$ bits, compared with 1 bit from separately applying the two-toss extractor to each pair. The construction illustrates why processing larger blocks can be more efficient.

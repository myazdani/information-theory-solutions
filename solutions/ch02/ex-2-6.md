# Exercise 2.6: Conditioning can change information either way

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 44. Logarithms are base 2 unless explicitly written as ln.

## Solution

## (a)
Let $`B`$ be a fair bit and set $`X=Y=Z=B`$. Then $`I(X;Y)=1`$, whereas $`I(X;Y\mid Z)=0`$.

## (b)
Let $`X,Y`$ be independent fair bits and set $`Z=X\oplus Y`$. Then $`I(X;Y)=0`$. Given either parity value, either bit determines the other, while each bit remains fair. Consequently $`I(X;Y\mid Z)=1`$.

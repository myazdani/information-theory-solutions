# Exercise 2.3: Minimum entropy

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 44. Logarithms are base 2 unless explicitly written as ln.

## Solution

Every summand $`-p_i\log_2p_i`$ is nonnegative, with the usual convention $`0\log 0=0`$. Therefore the minimum is 0. A positive summand vanishes only when $`p_i=1`$; because the masses sum to 1, equality holds precisely for the $`n`$ point-mass vectors (or the single vector when $`n=1`$).

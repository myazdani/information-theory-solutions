# Exercise 2.20: What run lengths retain

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 48. Logarithms are base 2 unless explicitly written as ln.

## Solution

Let $`n\ge1`$ be fixed. The run-length vector $`R`$ is determined by $`X^n`$. Conversely $`R`$ together with the final bit $`X_n`$ determines all runs, since their symbols alternate, and hence determines $`X^n`$. Thus
```math
H(X^n)=H(X_n,R)=H(R)+H(X_n\mid R).
```
In particular
```math
H(R)\le H(X^n)=H(X_n,R)\le H(R)+1.
```
The difference between the equal entropies is zero, and either difference from $`H(R)`$ is the same number $`H(X_n\mid R)\in[0,1]`$. The lower bound is attained when the final bit is determined by the runs; the upper bound is attained when, conditional on every attainable run vector, the two complementary bit strings are equally likely.

# Exercise 2.21: A probability-mass tail bound

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 48. Logarithms are base 2 unless explicitly written as ln.

## Solution

For $`0<d<1`$, the nonnegative random variable $`L=-\log_2p(X)`$ satisfies
```math
H(X)=\mathbb E L
\ge\mathbb E[L\mathbf1_{\{p(X)\le d\}}]
\ge\Pr\{p(X)\le d\}\log_2(1/d).
```
This is Markov's inequality written in the opposite direction. For $`d=1`$ the left side of the requested bound is zero, and for $`d>1`$ it is nonpositive, so the bound remains true. At $`d=0`$, $`\Pr\{p(X)=0\}=0`$; interpret the expression by its limiting bound (or simply state this zero-probability event separately), rather than treating $`0\cdot\infty`$ as an ordinary product.

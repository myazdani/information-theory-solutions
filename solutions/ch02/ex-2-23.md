# Exercise 2.23: An even-parity distribution

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 48. Logarithms are base 2 unless explicitly written as ln.

## Solution

For $`n\ge2`$, every strict subset of the coordinates is a collection of independent fair bits: fixing $`j<n`$ coordinates leaves exactly $`2^{n-j-1}`$ even-parity completions, so its probability is $`2^{-j}`$.

For an index $`1\le i<n-1`$, the coordinates $`X_1,\ldots,X_{i+1}`$ form a strict subset. Thus $`I(X_i;X_{i+1}\mid X_1,\ldots,X_{i-1})=0`$. At the final index, conditioning on the first $`n-2`$ bits fixes the parity relation between the last two bits. Each last bit is still fair, but either determines the other. Hence the requested list consists of $`n-2`$ zeros followed by 1 bit. For $`n=2`$, the list has only the final value 1.

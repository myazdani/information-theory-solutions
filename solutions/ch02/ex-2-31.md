# Exercise 2.31: When coarsening leaves conditional entropy unchanged

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 50. Logarithms are base 2 unless explicitly written as ln.

## Solution

Since $`g(Y)`$ is a deterministic function of $`Y`$,
```math
H(X\mid g(Y))-H(X\mid Y)=I(X;Y\mid g(Y))\ge0.
```
For finite entropies, equality holds exactly when $`X`$ and $`Y`$ are conditionally independent given $`g(Y)`$. Equivalently, for every supported $`y`$, the conditional distribution $`p(x\mid y)`$ depends on $`y`$ only through $`g(y)`$:
```math
p(x\mid y)=p(x\mid g(Y)=g(y)).
```
Thus all supported $`y`$ in a common fiber of $`g`$ must have the same conditional law of $`X`$. If both entropies are infinite, their formal equality alone need not imply conditional independence.

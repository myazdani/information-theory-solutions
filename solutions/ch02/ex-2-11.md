# Exercise 2.11: Normalized mutual information

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 45–46. Logarithms are base 2 unless explicitly written as ln.

## Solution

Assume $`0<H(X_1)=H(X_2)<\infty`$; the displayed ratio is undefined for zero or infinite denominator without an additional convention.

## (a)
Identical marginal distributions give
```math
\rho=\frac{H(X_2)-H(X_2\mid X_1)}{H(X_1)}
=\frac{I(X_1;X_2)}{H(X_1)}.
```

## (b)
Both mutual information and conditional entropy are nonnegative, so $`0\le\rho\le1`$.

## (c)
The value is zero exactly when $`I(X_1;X_2)=0`$, namely independence.

## (d)
The value is one exactly when $`H(X_2\mid X_1)=0`$. Thus $`X_2`$ is almost surely a function of $`X_1`$. Equal finite marginal entropies then also give $`H(X_1\mid X_2)=0`$, so this function is invertible on the supported values. The variables need not literally be equal.

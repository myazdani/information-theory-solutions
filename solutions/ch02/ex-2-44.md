# Exercise 2.44: Extracting a bit from a three-symbol source

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed pp. 53. Logarithms are base 2 unless explicitly written as ln.

## Solution

## (a)
Choose the fixed ordering $`A<B<C`$. If $`X_1<X_2`$, output 0; if $`X_1>X_2`$, output 1; if they are equal, produce no bit. For each distinct pair of symbols, the two orders have equal probability by independence. Thus the two output bits have equal probability for every unknown source distribution.

## (b)
Exactly one bit is produced with probability
```math
\mathbb E K=\Pr(X_1\ne X_2)=1-(p_A^2+p_B^2+p_C^2)\le\frac23,
```
with equality for the uniform three-symbol source. This is also optimal among deterministic, distribution-free extractors from two tosses. To see this, equal output probabilities for every $`p`$ force equal coefficients of each monomial $`p_i^2`$ and $`p_ip_j`$. Each diagonal class has one input and cannot be split between the two bit values; each off-diagonal class has exactly two equiprobable inputs, supporting at most one fair bit. The construction uses every such class. (For a known distribution, different schemes exploiting known probabilities could be available.)

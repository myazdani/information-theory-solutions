# Exercise 13.5: An LZ78 parse with an explicit terminal convention

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed p. 458.

## Solution

Start with dictionary index 0 for the empty string, and assign new phrases indices 1, 2, and so on. The parse is

```text
0 | 00 | 000 | 1 | 10 | 101 | 0000 | 01 | 1010 | 1 (terminal remainder)
```

Each complete phrase is its longest previous dictionary prefix followed by one new bit. The resulting index/literal pairs are

```text
(0,0), (1,0), (2,0), (0,1), (4,0),
(5,1), (3,0), (1,1), (6,0), (4,EOF).
```

The final 1 is already dictionary entry 4, so it is a terminal reference rather than a new phrase. With the original length known, the final pointer can be decoded without a new literal. With an explicit EOF symbol, the last pair above provides the termination convention.

For example, use $`\lceil\log_2 j\rceil`$ pointer bits for the $`j`$th new phrase, followed by its one-bit literal. The nine complete-phrase binary records are

```text
0 | 10 | 100 | 001 | 1000 | 1011 | 0110 | 0011 | 01100
```

and the terminal reference is pointer 0100 when the source length supplies framing. Other standard framing conventions can change the bitstream, but not these dictionary pairs. The experiment decodes the pairs and checks exact equality with the original string.

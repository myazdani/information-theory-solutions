# Exercise 13.7: A recurrence pointer plus the final symbol

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed p. 458.

## Solution

Let the finite alphabet have size $`A`$, and assume the stationary ergodic setting of the recurrence theorem in the chapter. Use a self-delimiting positive-integer code of length
$`\ell(r)\le\log_2 r+2\log_2(1+\log_2 r)+C`$.

### (a)
The per-symbol description length is

```math
\frac{\ell(R_{n-1})+\lceil\log_2 A\rceil}{n}
=\frac{\log_2R_{n-1}+O(\log(1+\log R_{n-1}))+O(1)}n.
```

The pointer reconstructs the first $`n-1`$ symbols from the common past, and the literal supplies the last one. The recurrence theorem $`\log_2R_k/k\to\overline H`$ gives almost-sure convergence to the entropy rate.

### (b)
The expectation argument can be made directly. Kac's recurrence formula and conditional Jensen imply

```math
E[\log_2R_k\mid X_1^k=x^k]
\le\log_2E[R_k\mid X_1^k=x^k]
=-\log_2P(X_1^k=x^k),
```

and hence $`E\log_2R_k\le H(X_1^k)`$. Jensen again bounds the expected self-delimiting overhead by $`2\log_2(1+H(X_1^k))+C=O(\log k)`$. Taking $`k=n-1`$ gives

```math
\limsup_{n\to\infty}\frac{E L_n}{n}
\le\lim_{n\to\infty}\frac{H(X_1^{n-1})+O(\log n)}n
=\overline H.
```

The code is uniquely decodable given the common past. Conditional source coding therefore gives $`EL_n\ge H(X_1^n\mid X_{-\infty}^0)=n\overline H`$. This proves expected-rate convergence as well. Recurrences overlapping the present boundary can be decoded sequentially by copying already reconstructed symbols, as in ordinary LZ; an implementation requiring matches entirely in the past can instead incur a sublinear framing/boundary overhead.

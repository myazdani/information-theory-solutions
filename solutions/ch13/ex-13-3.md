# Exercise 13.3: A Markov arithmetic-code prefix

Source: Cover and Thomas, *Elements of Information Theory*, 2nd ed. (2006), printed p. 458.

## Solution

Use lexicographic arithmetic intervals with 0 preceding 1, and half-open intervals at dyadic endpoints. The stationary first bit is fair. The successive intervals for the first few source prefixes are

```math
I(1)=[1/2,1),\qquad
I(10)=[1/2,5/8),\qquad
I(101)=[19/32,5/8),\qquad
I(1010)=[19/32,77/128).
```

The entire interval $`I(10)`$ is precisely the binary cylinder $`[0.100_2,0.101_2)`$. Therefore the first three encoded bits are **100**. These bits identify exactly the first **two source bits, 10**. Both third-bit continuations 100 and 101 have subintervals inside that cylinder, so the third source bit is not determined by those three code bits alone.

As an exact-rational cross-check, the given seven-symbol prefix has interval
$`[4919/8192,77/128)`$ and common encoded prefix 100110011. Its first three bits agree with the answer above. Binary-expansion ambiguity at dyadic endpoints is resolved by the stated half-open convention; exceptional eventually constant endpoints have probability zero for this source.
